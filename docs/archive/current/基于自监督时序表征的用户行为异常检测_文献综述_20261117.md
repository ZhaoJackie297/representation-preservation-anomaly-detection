# 基于自监督时序表征的用户行为异常检测研究综述

日期：2026-11-17  
范围：时间序列异常检测、自监督时序表征、SoftCLT/软对比学习、表征打分与幅度信息、CERT 用户行为异常检测  
说明：本文优先依据项目已阅读的论文、官方代码和文献摘录整理；未完成的系统检索不作为已综述证据。

## 摘要

用户行为异常检测面临标签稀缺、行为连续、个体差异显著以及异常形态多样等问题。传统统计、距离、重构和单类分类方法依赖人工特征或固定的正常边界，难以同时处理正常行为变化和低比例异常。近年来，自监督时序表征学习通过时间对比、上下文对比和掩码建模，从无标签序列中学习可迁移表示，为低标签条件下的异常检测提供了新思路。然而，现有方法仍存在三个关键假设：时间相邻样本通常被视为相似，不同实例通常被全部视为负样本，异常分数只依赖表示向量而忽略幅度信息。CERT 类用户行为数据使这些假设更容易失效，因为相似正常模式可能跨用户出现，时间邻近也不等于语义相同。

本文围绕上述问题梳理相关研究：首先介绍异常检测任务与评价；其次回顾 TS-TCC、TS2Vec、SimMTM 等时序自监督方法；然后分析 TNC、StatioCL、AdaTS、SoftCLT、CARLA 等方法对时间邻接和伪负样本的修正；进一步讨论 PAI 对表征幅度丢失的诊断与融合；最后结合 CERT、内部威胁检测和经典 iForest 基线，说明本项目“instance-soft + 欧氏表征库/PAI + 固定预算评价”的研究定位与边界。

## 1. 研究背景

互联网信息服务中的用户行为具有连续、情境依赖和群体关联等特征。异常可能表现为：

- 单日行为突变；
- 特定岗位、时间或组织情境下的上下文异常；
- 多个用户在一段时间内形成的协同异常；
- 缓慢积累、传播和衰减的风险。

真实数据通常缺乏充分异常标签，且异常比例极低。因此，研究重点逐渐从有监督分类转向正常模式学习、无监督异常检测和自监督表征学习。

现有异常检测方法大致经历了以下发展：

```text
统计/距离方法
→ 重构与预测模型
→ 深度单类分类
→ 自监督时序表征
→ 关系感知和异常信号感知的表示学习
```

本项目选择 TS2Vec 作为时序表征骨架，并在训练端和打分端分别讨论信息保全问题：训练端使用 SoftCLT 调整正样本关系，打分端比较余弦、欧氏表征库和 PAI 幅度组件。

## 2. 异常检测任务与评价

### 2.1 异常类型

Chandola 等将异常分为点异常、上下文异常和集合异常，并将检测方法归纳为分类、最近邻、聚类、统计、信息论和谱方法等[1]。这一分类仍是时序异常检测研究的基础。Pang 等进一步从监督方式、模型结构和学习目标三个维度整理了深度学习异常检测框架[2]。

在时序场景中，异常既可以是一个时间点，也可以是一段区间、一个变量关系变化，或者跨用户/跨实体的协同模式。2025 年的自监督时序异常检测综述指出，现有方法在数据稀缺、异常多样性、概念漂移和可解释性方面仍存在明显空缺[3]。

### 2.2 类别不平衡与评价

异常检测通常高度不平衡。Saito 和 Rehmsmeier 指出，在负类占主导时，ROC 曲线可能过于乐观，PR 曲线更能反映正类识别质量[26]。因此，本项目同时报告 PR-AUC 和 ROC-AUC，而不以单一 ROC 指标判断方法优劣。

仅有 PR/ROC 仍不足以覆盖实际告警场景。用户行为检测通常每天只能审查有限数量的高风险用户，因此还需报告固定预算 Top-K、告警冷却和事件命中。评价目标从“排序是否正确”扩展为“有限审查能力下能命中多少异常事件”。

### 2.3 传统方法仍有竞争力

Isolation Forest 通过随机特征和随机切分隔离样本，异常点通常具有更短路径[5]。它不依赖距离计算，训练和推理成本较低，是高维表格异常检测的经典基线。

Deep SVDD 将正常样本映射到超球中心，适合单类学习，但可能发生表示塌缩，并且对训练集污染敏感[6]。MSCRED、TranAD、Donut 和 SR-CNN 分别代表关系矩阵重构、Transformer 重构、季节性 KPI 建模和工业在线服务等路线[22-25]。

在 CERT 用户日特征上，iForest 并不弱。本项目新增基线显示，iForest 的点级 PR-AUC 与 Native TS2Vec 基本相同，低预算 Top-K 还略高。这说明单日行为离群点本身包含有效信号，不能把 iForest 设置为过度弱化的对照。

此外，真实行为分布会随时间发生突变、渐变、增量或重复变化。Gama 等提出的“漂移检测—适应”框架说明，静态训练得到的正常边界会逐渐失效[4]。这要求异常检测方法不能只报告单次静态评价，还需要时间外测试和版本化验证。

## 3. 时序自监督表征学习

### 3.1 对比预测与 InfoNCE

CPC 将表示学习写成上下文到未来目标的预测问题，并用 InfoNCE 优化互信息下界[7]。在理想条件下，InfoNCE 的最优判别函数与正负样本密度比相关。因此，负样本如何采样会直接影响表示所逼近的统计对象。

Wang 和 Isola 从球面表示的 alignment 与 uniformity 出发分析对比学习几何[27]；Eysenbach 等在额外假设下说明，时间对比表示可以与概率比和插值推断建立联系[28]。这些结果支持“正样本图决定表示几何”的观点，但不能无条件证明任意用户行为图都满足这些假设。

T-Loss 通过时间负采样和 triplet loss 学习多变量时序表示；TNC 进一步引入时间邻域，认为邻近窗口可作为正样本，并用去偏对比目标缓解采样偏差[8-9]。这些工作说明时间关系不能被简化为“同实例为正、其他全部为负”，但时间邻域本身也不是无条件成立的语义关系。

### 3.2 时间与上下文双对比

TS-TCC 使用弱增强和强增强构造两个视图，同时进行时间对比和上下文对比[10]。TS2Vec 则在不同时间尺度上进行层次对比，并将每个时间戳映射为可复用表示[11]。

TS2Vec 的原始目标包含：

\[
\mathcal L
=
\lambda\mathcal L_{\mathrm{inst}}
+
(1-\lambda)\mathcal L_{\mathrm{temp}}.
\]

其中 instance 项比较不同用户/实例，temporal 项比较同一实例的不同时间位置。这个结构适合通用时序表示，但默认假设“同一实例的不同时间位置可以形成稳定的时间对照关系”，对于用户行为数据并不总是成立。

### 3.3 掩码建模

SimMTM 通过邻域片段的加权组合恢复被遮时间片段，强调局部流形结构[12]。TimeMAE 将掩码表征与重建分支解耦[13]。与传统逐点重建相比，掩码方法能够减少对局部噪声的拟合，但如果训练目标和推理异常分数不同源，训练收益不一定会转化为异常检测收益。

因此，掩码建模可以提升表征质量，但不能自动解决正样本采样和异常评分的问题。

## 4. 软对比关系与伪负样本

### 4.1 时间邻域与伪负样本

标准时间对比往往将相近时间视为正、较远时间视为负。TNC 和 StatioCL 分别从时间邻域和非平稳状态角度指出，这种硬划分会引入伪负样本[9][15]。

AdaTS 进一步使用序列特定的动态时间分配，使时间相似度能够随样本变化，并可作为 TS2Vec 的插件[17]。TimeSiam 通过过去到当前的重建学习具有时间距离意识的双胞胎表示[16]。

这些研究表明：

1. 时间接近性可以作为归纳偏置；
2. 时间关系应当被软化或条件化；
3. “时间远即负”并不成立。

### 4.2 SoftCLT

SoftCLT 将实例和时间关系的硬权重替换为连续软权重，并在 TS2Vec 的层次结构上使用时间差生成软分配[14]。

本项目采用的类 instance 软权重为：

\[
w^I_{u,v}
=
\frac{2\alpha}
{1+\exp(\tau_I d^X_{u,v})},
\]

其中 \(d^X_{u,v}\) 是训练期用户行为画像距离。与只按时间差加权不同，这一权重是内容相关的：行为相似的不同用户可以获得弱正关系。

该适配的动机是 CERT 中“用户 ID 不同但正常行为相似”的假负例。标准 instance 对比会把这类用户全部推开，从而破坏正常行为流形；instance-soft 则把行为距离接近的用户重新加入弱正集。

### 4.3 异常注入与关系构造

CARLA 认为时间远离的窗口也可能是正常样本，并将多类合成异常作为负样本，直接学习正常与异常偏差[18]。CAROTS 通过保持或破坏变量因果关系的增强视图构造正负样本[19]。GenIAS 在潜空间生成更真实、多样的异常轨迹[20]。

这些方法共同表明：

- 正负样本的语义来源比单纯时间距离更重要；
- 异常信号可以在训练目标中显式构造；
- 合成异常必须避免分布过于人工化。

本项目没有把 instance-soft 解释为新异常生成算法，而是把它定位为：基于用户画像的正常关系重加权。

## 5. 表征打分与幅度信息

基于重构或预测的方法直接使用输入空间残差；基于表示的方法则先学习 embedding，再在表示空间计算距离或密度。

余弦距离只关注方向，欧氏距离同时包含方向和幅度。PAI 的研究指出，现有表示型异常检测方法常常产生幅度不敏感 embedding，导致幅度相关异常难以识别；PAI 通过比较余弦和欧氏评分，并融合 pointwise median/MAD 与局部均值漂移组件来补充幅度信息[21]。

本项目在 CERT 上的实验支持“欧氏表征库优于余弦”这一方向：同一 TS2Vec 表示下，欧氏距离在 PR/ROC 和固定预算事件命中上总体更稳定。PAI 的 magG/T2 组件则表现出点级与事件级方向冲突，因此只能作为辅助探索，不能写成全面有效。

需要区分：

1. 表征学习是否保留幅度；
2. 下游评分是否利用幅度；
3. 融合组件是否在独立数据上稳定。

三者不是同一个问题。

## 6. 用户行为与内部威胁检测

### 6.1 CERT 与日级表示

CERT 提供登录、设备、文件、邮件、HTTP、LDAP 和恶意场景标签，适合研究无监督用户行为建模。但它也是合成组织数据，不能直接代表真实企业。

本项目将原始日志聚合为 27 维用户日特征，再训练时序表示。这一处理保留了跨天趋势，但会丢失同一天内部的事件顺序和精确时间间隔。

### 6.2 事件级与真实系统

内部威胁研究正在向事件级上下文和高精度低误报发展。LAN 面向 CERT r4.2/r5.2 的活动级实时检测[34]；Facade 使用良性活动训练，在 Google 内部威胁场景强调 event-level context 和极低误报[35]；Log2Sig 则使用多尺度频率信号和双视图建模 CERT 日志[36]。

这些工作意味着：

- 日级 AUC 不能代表事件级实时检测能力；
- 实际系统更关注低误报和可审查证据；
- 固定 Top-K 和事件命中比单一全量排序更接近部署需求。

本项目的日级模型仍属于研究原型，不宣称已经达到真实内部威胁系统的工程要求。

## 7. 图关系与集体异常

导师课题强调跨用户群体关联。图异常检测综述将任务分为点、边、子图和社区级异常[31]。SpEagle 通过评论—用户—商品—店铺图进行集体分类，说明关系结构能补充单条样本特征[29]。CARE-GNN 通过关系感知邻居聚合缓解伪装连接[30]；GCN 和 GAT 提供了图表示学习的基础算子[32-33]。

本项目当前只保留 LDAP 组织字段，尚未完成稳定的跨用户集体异常模型。因此相关工作主要用于说明未来方向，不作为已完成实验。

## 8. 现有研究不足与本项目定位

### 8.1 现有不足

1. 多数时序对比学习默认时间邻近或增强视图为正，对用户行为中的跨用户相似性和上下文错配考虑不足；
2. SoftCLT、AdaTS 等工作主要处理通用时序，不直接解决 CERT 用户画像关系；
3. 表示型异常检测常忽略幅度信息，PAI 提供了诊断工具，但融合权重仍需严格审计；
4. 内部威胁研究强调事件级和低误报，而日级 CERT 实验容易高估实际能力；
5. PR-AUC、固定预算和事件召回是不同目标，不能混为一个结论；
6. iForest 等经典基线仍然很强，新方法必须与它们比较。

### 8.2 本项目的研究定位

本项目不以发明新的 TS2Vec 或 SoftCLT 基础算法为目标，而是研究：

> 如何在无监督时序表示学习中，用内容相关的实例软关系减少正常用户碰撞，并在打分端保留幅度信息，再通过 CERT 多版本、固定预算和外部基线进行严格评价。

对应实践：

| 研究问题 | 项目做法 |
| --- | --- |
| 用户间假负例 | 47 维训练期画像构造 instance-soft 权重 |
| 时间关系与实例关系的区分 | T0/T1/T2/T3/T4 受控消融 |
| 余弦丢失幅度 | 余弦 vs 欧氏表征库 |
| 幅度组件稳定性 | magG/T2/PAI-A1/A3 与官方权重敏感性 |
| 经典非时序基线 | iForest-27D |
| 固定审查预算 | K=5/10/20、7 天冷却、事件命中 |
| 外部有效性 | r4.2、r5.2、r6.2、SMD |

## 9. 结论与研究机会

时序自监督异常检测已经从重构和预测扩展到对比学习、掩码建模、异常注入和关系建模。现有研究普遍承认：时间邻接不等于语义正样本，不同实例也不能全部视为负样本。SoftCLT、TNC、StatioCL、AdaTS 和 CARLA 从不同角度修正了这些问题。

本项目进一步把“不同用户之间也可能存在正常语义邻接”作为切入点，使用训练期用户画像生成 instance-soft 权重。实验表明，instance-soft 改善正常邻域保持和有效秩；temporal-soft 具有局部时间平滑作用，但未形成稳定的端到端增量。打分端则以欧氏表征库作为主证据，PAI 组件作辅助审计。

下一阶段可从数学角度继续研究：

1. 内容相关正样本图的谱偏置；
2. 时间软权重的低通作用；
3. 图平滑与异常可分性的关系；
4. 随机画像核和合成异常形态的对照。

这些分析应服务于解释现有实验，而不是继续增加未经验证的模块。
