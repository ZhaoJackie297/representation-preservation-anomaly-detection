# 下一课题：SoftCLT 软正样本图的谱偏置与异常可分性

日期：2026-11-17  
定位：数学分析 + 实验验证，不新增拼接式模块  
依托：TS2Vec / SoftCLT / CERT r4.2、r5.2、r6.2

## 一、研究问题

当前实验显示：

- instance-soft 明显改善正常邻域保持和有效秩；
- temporal-soft 在 temporal-only 方案中能改善时间残差的可分性，但不能替代 instance 对比；
- 在 instance-soft 上再加 temporal-soft，端到端 PR/ROC 没有提高。

本课题要回答：

1. 两类软正样本权重分别诱导了什么表示空间算子？
2. 为什么内容相关的 instance 图能改善语义邻域，而内容无关的 temporal 图不能自动改善最终检测？
3. 图平滑、语义对齐和异常可分性之间是否存在严格关系？
4. 什么样的异常类型和数据条件下，temporal-soft 理论上应当有效？

## 二、数学对象

### 2.1 instance 图

\[
W_I(u,v)
=
\frac{2\alpha}
{1+\exp(\tau_I d^X_{u,v})}.
\]

其中 \(d^X_{u,v}\) 来自训练期 47 维用户画像。

### 2.2 temporal 图

\[
W_T(t,s)
=
\frac{2}
{1+\exp(\tau_T2^d|t-s|)}.
\]

### 2.3 图算符

定义度矩阵 \(D_W\)、拉普拉斯 \(L_W=D_W-W_W\)，以及归一化 Dirichlet 能量：

\[
R_W(Z)
=
\frac{\operatorname{tr}(Z^\top L_WZ)}
{\operatorname{tr}(Z^\top D_WZ)}.
\]

同时定义高频残差：

\[
h_W(z_i)
=
\left\|
z_i-
\frac{\sum_jW_{ij}z_j}
{\sum_jW_{ij}}
\right\|^2.
\]

### 2.4 需要推导的梯度结果

对归一化点积相似度和 weighted positive InfoNCE，尝试证明：

\[
\nabla_{z_i}\mathcal L_i
=
\frac{1}{\tau}
\left[
\sum_k p_{ik}z_k
-
\frac{\sum_jw_{ij}z_j}
{\sum_jw_{ij}}
\right].
\]

该式说明：

- 表示被拉向软正样本加权重心；
- 同时被 softmax 负样本整体推开；
- \(w\) 不是普通温度，而是目标重心的定义。

需要严格核对符号、归一化和 hierarchy 聚合后的形式。

## 三、核心假设

### H1：instance-soft 是语义图重校准

标准 instance 对比会产生跨用户假负例。内容相关软边把行为相似用户加入弱正集，使表示局部邻域更接近数据行为邻域。

可检验预测：

- 数据 kNN 与表示 kNN 一致率提高；
- 局部距离 Spearman 提高；
- 内容邻域 residual 的异常 AUC 提高。

注意：H1 不要求 instance Dirichlet energy 降低。初步结果中 T3 的 instance Dirichlet 反而高于 T0。

### H2：temporal-soft 是时间低通算子

时间软核是 Toeplitz 平滑核，会压低用户内高频时间差。

可检验预测：

- temporal Dirichlet energy 降低；
- 时间高频残差的异常 AUC 可能提高；
- 但如果最终评分使用表征库，局部残差收益不一定传到端到端指标。

### H3：两类图的收益目标不同

- instance 图优化跨用户语义邻域；
- temporal 图优化用户内时间连续性；
- 当前异常主要由跨用户/个人历史偏离定义，因此 instance 图比时间图更贴近最终任务。

### H4：temporal-soft 只在特定异常形态下增益

预测：

- 对缓慢长期漂移，temporal-soft 可能有帮助；
- 对孤立点异常，可能帮助有限或伤害；
- 对持续平滑异常，时间平滑先验无法区分正常与异常。

## 四、已有三 seed 初步结果

| 模型 | instance Dirichlet | temporal Dirichlet | instance residual ROC | temporal residual ROC | 最终 test PR / ROC |
| --- | ---: | ---: | ---: | ---: | ---: |
| T0 | 0.2937 | 0.2829 | 0.7950 | 0.6071 | 0.007447 / 0.816112 |
| T1 | 0.0936 | 0.4555 | 0.7756 | 0.6325 | 0.005496 / 0.759326 |
| T2 | 0.1265 | 0.3457 | 0.7606 | 0.6966 | 0.006252 / 0.772159 |
| T3 | 0.3456 | 0.2452 | **0.8407** | 0.7651 | **0.008922 / 0.842132** |
| T4 | 0.3352 | **0.2395** | 0.8398 | **0.7717** | 0.008867 / 0.841593 |

关键分解：

- T1→T2：temporal Dirichlet `-0.1098`，temporal residual ROC `+0.0642`，3/3 seed 同向；
- T3→T0 反向看：instance residual ROC `+0.0458`，temporal residual ROC `+0.1580`，kNN 和有效秩明显提高；
- T4→T3：temporal Dirichlet `-0.00565`，temporal residual ROC `+0.00660`，但 instance residual 1 正 2 负，最终 PR/ROC 轻微下降。

结论：

> temporal-soft 的局部低通效果是真实存在的；“没有独立收益”必须限定为没有端到端稳定收益，而不能写成算法完全无效。

## 五、实验设计

### E-S1：图核真实性

固定编码器、数据、epoch 和评价，比较：

1. hard instance；
2. 真实 47 维画像核；
3. 随机用户画像核；
4. 画像特征置换核；
5. 全部权重置常数的完全图核。

判据：

- 如果随机核与真实核同样有效，instance-soft 的解释不成立；
- 如果只有真实核提高 kNN 和 residual AUC，才能支持内容相关语义图假设。

### E-S2：时间核频率响应

固定 instance-soft 和 `lambda=0.5`，扫描：

```text
tau_T ∈ {0.25, 0.5, 1.0, 1.5, 3.0, 6.0}
```

只允许在 validation 上选择，test 仅用于最终评价。

输出：

- 时间 Dirichlet energy；
- temporal residual ROC；
- 表示有效秩；
- 最终 PR/ROC 和固定 K。

### E-S3：异常形态合成实验

在同一正常序列上注入四类异常：

1. point spike；
2. local contextual anomaly；
3. collective anomaly；
4. slow smooth drift。

对每类异常分别比较 T1/T2/T3/T4，检验：

- point spike 是否更依赖 instance 图；
- slow drift 是否更依赖 temporal 图；
- temporal-soft 是否只在后两类中产生优势。

### E-S4：异常频率投影

将验证/测试表示投影到不同图频率子空间，比较异常能量分布：

\[
\operatorname{Proj}_{\lambda_k}(Z),
\qquad
\operatorname{Proj}_{\lambda_k}(h_W).
\]

检验异常的异常信号是否确实集中在低时间频率，还是集中在局部高时间频率。

### E-S5：下游评分一致性

同时比较：

- masked L1；
- 余弦表征库；
- 欧氏表征库；
- 图 residual 直接分数；
- PAI-A1。

目的：判断图 residual 的改善为何没有传到最终表征库评分。

## 六、评价指标

### 数学/几何指标

- normalized instance Dirichlet energy；
- normalized temporal Dirichlet energy；
- 数据 kNN 与表示 kNN 一致率；
- 局部距离 Spearman；
- 有效秩；
- 平均范数；
- graph residual ROC/PR。

### 检测指标

- 点级 PR-AUC、ROC-AUC；
- K=5/10/20 固定预算事件命中；
- 告警提前量；
- 多 seed 配对差值；
- 分层 bootstrap 置信区间。

### 必须避免

- 用测试集选择 `tau_I`、`tau_T` 或 fusion weight；
- 用 residual AUC 代替最终检测器；
- 用 3 seed 的 3/3 方向一致性声称统计显著；
- 将图能量下降与异常可分性提高直接画等号。
