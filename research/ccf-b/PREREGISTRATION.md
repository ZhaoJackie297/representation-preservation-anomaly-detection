# AdaGraph-SoftCLT 预注册表

版本：v1.1
冻结日期：2026-11-18

本预注册晚于 R0 实验。新增组件和比较按确认性处理，R0 已使用的数据不重新宣称为盲测。所有偏离本文件的修改必须写入版本化勘误。

## 1. 数据集地位

| 数据 | 地位 | 规则 |
| --- | --- | --- |
| CERT r4.2 | 开发与方向性复现 | 用于调试、pilot 和无标签选参；不提供最终确认性 p 值 |
| CERT r5.2 | 已见外部复验 | 可作为工程复验，但因 R0 已使用，不宣称为盲测 |
| CERT r1 | 计划中的独立确认集 | 必须先通过标签、账户映射、时间切分和处理口径审计；未通过则暂停 B 类确认 |
| CERT r6.2 | 压力审计 | 仅 5 个事件，不进入显著性检验 |
| SMD | 打分端验证 | 训练端固定 A0，不运行 AdaGraph 用户图 |
| PSM/SMAP/MSL | 打分端外部验证 | 不用于 AdaGraph 用户图结论 |

预注册确认结论只在 CERT r1 审计通过后执行。若 r1 不能可靠构造用户日与事件标签，则停止 B 类确认性声明，不把 r5.2 的已见结果改称盲测。

## 2. 研究假设

- H1a：画像先验锚定的软图相对纯表示图降低假负样本偏差。
- H1b：AdaGraph 相对固定画像软权重取得端到端收益。
- H2a：在其他组件固定时，画像锚的边际贡献为正。
- H2b：在其他组件固定时，EMA 教师的边际贡献为正。
- H2c：画像关系信息不是随机稀疏加权带来的假收益。
- H3：AdaGraph 的收益不能由更长训练或重复优化器重启解释。
- H4：训练端 AdaGraph 与打分端欧氏库的交互为正。H4 为探索性假设。

不再声称画像锚和 KL 信任域是两个可以独立开关、独立识别的组件。二者由同一个 `beta` 控制，只能研究锚/信任强度的剂量响应。

## 3. 训练变体

| 编号 | 定义 | 用途 |
| --- | --- | --- |
| A0 | TS2Vec 硬实例负样本 | 原始参照 |
| A1 | 固定 47 维画像软权重，单阶段 `B` | R0 主基线 |
| A1-sparse | 固定画像图，仅按 `P` 选 top-m 并重归一化 | 稠密/稀疏画像对照 |
| A1+ | 固定画像图，连续训练到与 A3/A4 相同总步数 | 等算力对照 |
| A2 | 当前表示、无 EMA、无画像锚，两阶段 `2B` | EMA×锚 的 no/no 单元 |
| A3 | 画像锚 + EMA + KL 信任域，一次更新，`2B` | AdaGraph 单轮核心 |
| A4 | AdaGraph 两轮更新，`3B` | 主候选方法 |
| A3-noAnchor | EMA、无画像锚，`beta=0`，两阶段 `2B` | EMA×锚 的 yes/no 单元 |
| A3-noEMA | 画像锚 + 当前表示 + 信任域，两阶段 `2B` | EMA×锚 的 no/yes 单元 |
| A3-product | 替代融合规则 `P_m * exp(-d_tilde/tau)`，不满足 KL 缩放 | 检验替代融合规则，不称“去信任域” |
| A3-hard | 同画像和 EMA 支撑集，但正关系取 1、其余取 0 | 软/硬权重对照 |
| A5a | 度保持随机图 | 排除随机稀疏图 |
| A5b | 错误画像锚：`P_perm(u,v)=P(pi(u),pi(v))` | 排除画像关系信息 |
| A6 | 仅画像中位数维度 | 画像构造消融，放附录 |
| A7 | NNCLR 近邻正样本 | 近邻对比基线 |
| A8a | Incremental False Negative Detection 适配 | 动态假负检测基线 |
| A8b | False Negative Cancellation 适配 | 假负抵消基线 |
| A9 | 固定画像图，三段 `1B` 权重续训和逐段优化器重置 | 等轮数/重启对照 |

### 训练预算

- 预算单位：优化器步数，不是 epoch 数。
- A1 和 A8 等方法的基础预算记为 `B`。
- A3 为 `2B`；A4 为 `3B`。
- A1+ 使用连续 `2B` 或 `3B`，并按总预算重新设置 warmup-cosine 调度。
- A4 后两段和 A9 三段均从上一段权重继续，每段重置优化器状态。
- 逐种子配对要求同一 seed 下的数据顺序、图初始化、模型初始化和 batch 顺序相同。

## 4. 无标签超参数选择

所有训练方法和基线使用同一选择协议：

1. 在训练期内部再切出一段完全早于首个真实恶意事件的时间作为 inner-validation。
2. 从 inner-validation 的正常行为注入固定合成异常：幅度尖峰、多通道突发、低幅缓慢漂移。
3. 每个机制固定 3 个强度，仅使用合成标签评价。
4. 选择分数：

```text
J = mean synthetic PR-AUC across 3 mechanisms x 3 strengths
```

5. 为避免耦合打分端搜索，`J` 固定使用 S2 欧氏表征库。
6. 每个方法族最多 20 次训练：12 个候选各跑 1 个调参 seed；前 4 名各补 2 个调参 seed。
7. 若 `J` 相同，依次比较 RankMe 有效秩和较低图漂移。
8. 调参完成后，在完整训练期上重训 10 个正式 seed。
9. A7、A8a、A8b 和深度基线使用同样的 inner-validation、合成异常和 20 次上限。

真实 validation/test 标签不得参与模型选择。合成异常生成器、强度和随机种子预注册后固定。

## 5. 主终点与推断

共同主终点：

- PR-AUC；
- `K=10` 固定预算事件召回。

预注册 10 个种子：`20261116` 至 `20261125`。

主推断：

1. 对每个 seed 计算配对差值；
2. 先在 10 个 seed 上求平均；
3. 条件于已训练模型，对用户/事件簇做配对 bootstrap；
4. bootstrap 重复 10,000 次；
5. 用户日是协变量，不作为独立重采样单位。

显著性与区间：

- 单侧 `alpha=0.025`，对应双侧 95% 区间；
- 优效性 p 值：`(1 + #{Delta* <= 0}) / (B + 1)`；
- 非劣效性 p 值：`(1 + #{Delta* <= delta_margin}) / (B + 1)`；
- 确认性 p 值进入 Holm 校正；
- 置信区间只作为效应量和不确定性展示，不替代预注册 p 值规则。

### K=10 固定排名 bootstrap

采用固定排名方案，不在 bootstrap 中重新计算每日 Top-K：

1. 原始用户池上固定每个模型的每日 Top-K 名单；
2. 按用户聚类重采样，保留用户的全部日期、告警命中和事件；
3. 多用户事件作为同一事件簇整体重采样，避免拆散事件；
4. 在固定名单上计算重采样后的召回；
5. 不增加候选池、不重新排序、不产生重复用户的新 Top-K。

PR-AUC 的用户聚类 bootstrap 使用用户多重权重计算；事件级 bootstrap 只作敏感性分析。

## 6. 确认性比较

确认性数据集只有通过审计的 CERT r1。

确认性比较：

1. A4 vs A1；
2. A4 vs A1+（`3B`）；
3. A4 vs A7；
4. A4 vs A8b；
5. A4 vs A9。

每个比较有两个共同主终点。Holm 在 r1 上覆盖 `5 x 2 = 10` 个检验。

- A4 vs A1 是端到端收益，不作组件归因。
- A4 vs A1+ 和 A4 vs A9 是算力归因。
- A4 vs A7/A8b 是已有方法对比。

Gate 1 的算力主张采用交并规则：A4 必须相对 A1+ 和 A9 在**两个共同主终点**上均满足优效性。

A7/A8b 的比较采用“至少一个主终点优效，且两个主终点均非劣”：

- PR-AUC 非劣界：参考方法的 `-5%` 相对值；
- K=10 召回非劣界：参考方法的 `-5%` 相对值。

A8a 是显式删除假负样本的抑制式方法，与 A8b 的软抵消机制不同，因此保留为探索性基线；其全部结果必须报告，但不进入主确认性家族。

正式开跑前必须读取 R0 结果完成最小可检测效应估计：

- 使用 10 个种子的观测方差和用户聚类 bootstrap 宽度；
- 估计 PR-AUC 与 K=10 召回在 `alpha=0.025`、Holm 和 80% 功效下的最小可检测效应；
- 若实际可检测效应大于业务上有意义的差异，则调整样本设计或终止 B 类主张。

## 7. 机制分析

机制比较单独构成预注册小家族，在 r1 上使用 `alpha=0.025` 和 Holm：

1. A3 vs A3-noAnchor；
2. A3 vs A3-noEMA。

每个比较使用两个共同主终点，共 4 个检验。A3-product、A3-hard、β 剂量响应、A2 等其他对照标记为机制或探索性分析。

画像/信任强度使用剂量响应：

```text
epsilon = {0, 0.001, 0.01, 0.05, 0.1, 0.2, 0.5, infinity}
```

- `epsilon=0` 对应纯画像图；
- `epsilon=infinity` 对应纯表示图；
- 中间网格对应不同信任域强度；
- 逐用户记录实际 `beta`、有效温度和 KL。

EMA 与锚使用 2×2 单元：A4、A3-noAnchor、A3-noEMA、A2。

## 8. 假负偏差与关系质量

### FN 代理量

使用 CERT LDAP 的部门/角色关系作为评价标签，不进入训练：

```text
PeerMass(u) =
  sum_{v: same department and role} W(u,v)
```

报告：

- `PeerMass@top-m` 的均值；
- Top-10 邻居的组织结构一致率；
- 同部门、同部门且同角色的加权召回。

LDAP 只用于评价和半合成验证，不进入 `P`、`d_EMA`、图更新或调参。

### 邻域一致率

定义原始 47 维画像邻域与学习后用户表示邻域的 Top-10 Jaccard：

```text
NCA@10 =
  mean_u |N10_raw(u) intersect N10_repr(u)| /
         |N10_raw(u) union N10_repr(u)|
```

非劣比较对象为同一预算下的 A1+。95% CI 下界不得低于 `-0.02`。

### 有效秩

使用 RankMe 有效秩相对 A1+ 的比值：

```text
ER_ratio = ER_method / ER_A1plus
```

非劣界为 0.90，即 95% CI 下界不得低于相对有效秩 0.90。

### 半合成验证

构造带已知 peer class 的用户行为数据：

1. 正常行为生成器按部门/角色设置潜在类；
2. 同类用户共享强度分布，但保留个体噪声；
3. 异常按幅度、上下文和集体机制注入；
4. 比较候选图与真实潜在 peer 关系的 AUC、PeerMass 和检测性能。

半合成数据只用于验证 FN 代理量，不替代真实 CERT 结论。

### 外部基线适配

所有表示学习基线统一到用户级实例：

- 每个用户训练期序列是一个 instance；
- 用户表示由训练期活跃日表示归一化平均得到；
- NNCLR 的支持集使用同一 EMA 用户表示库，`k` 与 AdaGraph 的 top-m 网格一致；
- Incremental False Negative Detection 和 False Negative Cancellation 都在相同用户级负样本池上运行；
- 基线若必须偏离原论文，需在附录记录输入、正负样本单位和训练步数的改动。

## 9. Gate 1

以下条件全部满足才算通过：

- r1 标签和账户映射审计通过；
- A4 相对 A1+ 和 A9 在两个共同主终点上均优效；
- A4 相对 A7/A8b 至少一个主终点优效，且两个终点均非劣；
- A4 相对 A1 有端到端正向收益；
- A4 相对 A5a/A5b 至少一个共同主终点方向为正，且至少 8/10 seed 为正；
- NCA@10 非劣界满足；
- ER_ratio 非劣界满足；
- A3 相对 noAnchor/noEMA 的机制家族至少一个主终点正向；
- 不存在有效秩持续下降、表示各向同性异常上升或异常用户进入正常核心的事后警示。

任一关键条件失败，不把 AdaGraph 写成 B 类新方法。

## 10. 数据结构与实现规格

### 画像先验 `P`

- 使用现有 47 维训练期鲁棒画像；
- 排除部门、角色、团队和 LDAP 派生字段；
- 每维用训练用户的中位数和 IQR 标准化；
- `D_profile` 为欧氏距离；
- 带宽 `h=median(D_profile)`；
- `P_raw(u,v)=max(exp(-D_profile(u,v)^2/(2h^2)), 1e-12)`，`u!=v`；
- 对角置 0，然后逐行归一化；
- 支撑集上的 `P_m` 再从上述正概率重新归一化，保证 KL 有定义。

### EMA 用户表示

- 每阶段开始时 EMA 教师权重直接复制学生权重，不初始化为零；
- 只使用训练期活跃日；
- 先对每日时间戳表示做 L2 归一化，再对活跃日均值归一化，得到用户表示；
- `d_EMA(u,v)=1-cosine(z_u,z_v)`；
- 行中位数归一化；
- 行中位数下限 `1e-6`；
- EMA decay 搜索只使用 `{0.99, 0.995}`，不使用在 B 步内几乎不更新的 0.999。

### 支撑集与 KL

- `score(u,v)=P(u,v)*exp(-d_tilde(u,v)/tau)`；
- 支撑集 `S_m(u)` 按 score 取 top-m；
- 在支撑集上重归一化 `P_m`；
- KL 只在 `S_m(u)` 上计算；
- beta 二分容差 `1e-6`，最大 64 次；
- 若无可行 beta，回退 `beta=1` 并记录失败。

### W 到 SoftCLT

- 每行 `W_beta` 在支撑集上归一化为概率分布；
- SoftCLT 自权重保持 1；
- 对 `i!=j`，正关系权重直接取 `W_beta(i,j)`；
- 不按 m 再乘缩放系数，因此邻居总权重固定为 1，与支撑集大小无关；
- 未进入支撑集的用户对作为普通负样本。

### EMA 更新

- EMA 在阶段内逐步更新，并记录教师-学生余弦距离；
- 要求 `B >= 3/(1-decay)`；否则该 decay 标记为低有效更新并不得用于正式模型。

## 11. 参数搜索范围

- EMA decay：`{0.99, 0.995}`；
- tau：`{0.05, 0.1, 0.2, 0.5, 1.0}`；
- epsilon：`{0, 0.001, 0.01, 0.05, 0.1, 0.2, 0.5, infinity}`；
- top-m：`{10, 20, 50}`；
- A7 的近邻数 `k` 使用同一 `{10,20,50}` 网格；
- 学习率和 weight decay 使用相同搜索空间；
- 每个方法族最多 20 次调参训练。

当 `epsilon=0` 时直接取纯画像图；当 `epsilon=infinity` 时直接取纯表示图，并记录 beta 实际值。

## 12. 算力口径

R0 单次 `B=10 epochs` 的实测耗时大约为：

- r4.2：`149–194 s`；
- r5.2：`168–411 s`；
- r6.2：`145–261 s`。

A4 的 `3B` 预计约 `8–20 min` 一次，具体取决于数据和机器状态。按单张 RTX 5060、24 小时运行，计划将调参限制在 r4.2 的内部验证，并把深度基线限制为 r5.2/SMD 的最低必要矩阵。正式开跑前需用 run registry 记录实际 GPU 小时；若预计超过 8 周预算，先削减探索性变体，不削减主比较。

## 13. 批次

### Pilot

r4.2，1–2 个 seed：A1、A1-sparse、A1+、A3、A5a、A5b、A7。
Pilot 只判断效应方向，不作确认性推断；一旦使用 r4.2 测试期方向决定是否进入第二批，r4.2 即失去最终盲测地位。

### 第二批

Pilot 有信号后：r4.2 + r5.2，10 seed，运行 A2、A4、A8a、A8b、A9 和机制消融。

### 确认与安全

r1 审计通过后运行确认性矩阵。深度基线、S×A 和完整安全实验在 Gate 1 通过后启动。

## 14. 标签与早停

- 图更新、调参和早停不使用真实异常标签；
- synthetic anomaly 标签只来自固定生成器；
- LDAP 只用于评价；
- “异常用户进入正常核心比例”只作事后诊断；
- 训练期早停只允许使用训练损失、inner-validation 损失、有效秩、各向同性和图漂移；
- 任何使用测试标签或真实 validation 标签选择模型的运行从主分析中排除。
