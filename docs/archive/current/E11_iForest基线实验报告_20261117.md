# E11：iForest 外部基线实验

日期：2026-11-17  
数据集：CERT r4.2  
定位：新增外部基线，不修改 E0–E10

## 一、实验目的

使用经典无监督表格异常检测方法 IsolationForest，检验双端优化是否不仅在 TS2Vec 内部对照中有效。

## 二、实现口径

- 输入：与 S2 相同的 27 维用户日特征；
- 每行是一个活跃用户日；
- 不使用 47 维用户画像；
- 计数特征使用 `log1p`；
- 时间特征 `-1` 先转为 `NaN`，再用训练期活跃行中位数回填；
- 使用训练期数据拟合 `StandardScaler`；
- 只在训练期拟合 IsolationForest；
- 分数约定：`-score_samples`，越大越异常；
- 评价复用现有 Top-K、7 天冷却和 `evaluate_alert_system`；
- 最终表格只报告 test。

注意：为完全复用现有全时间轴 `build_alerts` 的 7 天冷却逻辑，分数矩阵覆盖所有活跃日；模型仍只在训练期拟合，validation 和 test 都没有参与拟合或参数选择。

模型配置：

```python
IsolationForest(
    n_estimators=500,
    max_samples="auto",
    contamination="auto",
    random_state=20261116,
    n_jobs=-1,
)
```

没有超参数搜索。r5.2、r6.2 和 SMD 本轮未跑。

## 三、实验结果

| --- | ---: | ---: | ---: | ---: | ---: |
| iForest − T0 | +0.0000002 | +0.000853 | +2.67 | +2.00 | 0.00 |
| T4+PAI-A1 − iForest | +0.007708 | +0.064802 | +1.00 | +3.00 | +5.00 |

## 四、解释

1. iForest 是一个有竞争力的表格基线：点级 PR-AUC 与 T0 基本相同，ROC-AUC 略高。
2. iForest 在低预算 K=5、K=10 上优于 T0，说明单日表格离群点本身包含一定异常信息。
3. T4+PAI-A1 相对 iForest 在 PR-AUC、ROC-AUC、K=5、K=10、K=20 全部领先。
4. 因此可以加入论文表述：

> 双端优化相对经典表格异常检测基线在点级排序和固定预算事件命中上仍保持优势。

应同时保留一句边界：

> iForest 作为单日表格模型已经接近 Native TS2Vec，说明只依赖时序建模并不会自动带来收益，关键仍是 instance-soft 对表示邻域的改善。
