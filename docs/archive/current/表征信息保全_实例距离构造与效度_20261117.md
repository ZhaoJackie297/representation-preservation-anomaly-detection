# 表征信息保全：SoftCLT 实例距离构造与效度

日期：2026-11-17  
适用范围：CERT r4.2、r5.2、r6.2 的 instance-soft 实验

## 一、结论

本项目实例分支使用的是 **47 维训练期用户画像欧氏距离**，不是 SoftCLT 论文中的 DTW：

\[
\phi_u=
\left[
\operatorname{median}_{k}(x_{u,k}),
q_{90,k}(x_{u,k}),
\operatorname{active\_fraction}_u
\right]_{k=1}^{23}
\]

\[
D_{uv}=\|\tilde\phi_u-\tilde\phi_v\|_2
\]

其中 \(\tilde\phi_u\) 是训练期跨用户标准化后的画像。前 20 个特征是登录、设备、文件、邮件和网页计数；另 3 个是首次登录分钟、最后登出分钟和活跃跨度。因此：

```text
23 个 median + 23 个 q90 + 1 个 active fraction = 47 维
```

此前报告写“47 维”而代码实际只取 20 个计数特征，构成 41 维。该不一致已修正，受影响的 SoftCLT 实例实验按 47 维重新运行。

2026-11-17 的缺失值审计还修正了另一个实现问题：原始 S1 用 `-1` 表示“当天没有登录/登出/有效活跃跨度”。旧画像代码中的 `np.maximum(values, 0.0)` 会把 `-1` 改成 `0`，从而把缺失误当成零点。修正版先将负时间值转为 `NaN`，逐用户使用 `nanmedian/nanquantile`；若某用户的某特征完全缺失，只用训练期人群该特征中位数回填。修正版结果写入独立目录 `missing_safe_v2_20261117`，旧结果未覆盖。

## 二、为什么需要数据空间距离

SoftCLT 将普通对比学习的硬正负分配改成软权重：

\[
w_I(u,v)=
\frac{2\alpha}
{1+\exp(\tau_I D_{uv})}
(1-\alpha)\mathbf 1[u=v]
\]

当两个实例在数据空间越接近时，\(D_{uv}\) 越小，软正权重越高。其目的不是把“相似样本”当成完全正样本，而是减轻类碰撞和假负样本。

对 CERT 而言，直接把用户行为当普通单变量序列做 DTW 有三个问题：

1. 用户日志是 23 维稀疏日计数，很多日期没有某类行为；
2. 不活跃日、缺失行和真实零行为会混入同一条对齐路径；
3. 1000 至 4000 名用户两两 DTW 的构造和调参成本过高。

用户画像距离保留四类与内部威胁最相关的行为信息：

- 典型强度：逐特征 median；
- 尾部强度：逐特征 90% 分位；
- 时间习惯：首次登录、最后登出和活跃跨度；
- 行为持续性：活跃日比例。

## 三、数学解释

设标准化画像为：

\[
\tilde\phi_{u,k}
=
\frac{\phi_{u,k}-\mu_k}{s_k}
\]

则：

\[
D_{uv}^2
=
\sum_k
\left(
\frac{\phi_{u,k}-\phi_{v,k}}{s_k}
\right)^2
\]

它是协方差矩阵限制为对角阵时的马氏距离。跨用户标准化使不同量纲和不同离散程度的特征进入同一个距离尺度；它与“对每个特征除以总体标准差后再做欧氏距离”完全等价。

距离矩阵只在非对角元素上执行 Min-Max，然后令：

\[
\tau_I
=
\frac1{\operatorname{median}_{u<v}(D_{uv})}
\]

```
alpha = 0.5
```

带宽和融合系数都由训练期数据决定，不使用测试标签或测试期分数选择。

## 四、构造效度实验

为了检验画像距离是否真的描述稳定的用户行为关系，将每份 CERT 的训练期从中点切成前后两半：

1. 分别在两半上重建 47 维画像；
2. 各自计算用户两两距离；
3. 计算两组非对角距离的 Spearman 秩相关；
4. 计算每个用户 Top-10 邻居集合的重合率。

结果：

| 数据集 | 距离矩阵秩相关 | Top-10 邻居重合率，41 维修正版 | Top-10 邻居重合率，47 维修正版 |
| --- | ---: | ---: | ---: |
| r4.2 | **0.978** | 0.640 | **0.700** |
| r5.2 | **0.965** | 0.534 | **0.625** |
| r6.2 | **0.958** | 0.317 | **0.422** |

解释：

- 前后半段距离矩阵高度一致，说明画像不是单一时间段偶然形成的；
- 加入 3 个时间特征后，Top-10 正常邻域关系在三个数据集上均更稳定；
- r6.2 用户规模更大、活动更稀疏，因此邻居重合率较低，这与数据难度一致。

该实验只使用正常训练期数据，不使用恶意标签。

## 五、它不是 DTW 的等价替代

必须明确以下限制：

1. 画像距离忽略完整时间顺序、状态转移和跨通道滞后关系；
2. median/q90 会压缩短暂事件序列的形状信息；
3. 对角标准化忽略特征间相关性；
4. 对极端稀疏用户，活跃比例和少数分位数仍可能不稳定；
5. 因此它是 **CERT 的第一版可复现适配假设**，不是论文原始 DTW 的等价实现。

申报书应写“针对稀疏用户日计数构造训练期画像距离，并通过前后半段稳定性验证其构造效度”，不能写“用画像距离替代 DTW 且效果相同”。
