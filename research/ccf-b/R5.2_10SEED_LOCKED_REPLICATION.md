# r5.2 Coverage-PAI 10-seed locked replication

Date: 2026-11-19.

Status: fixed r5.2 version replication completed.

The same four fixed cells, PAI weights, and primary endpoints from r4.2 were
used. No parameter was tuned on r5.2.

## 1. Setting

```text
users:    2000
timeline: 517 days
split:    train indices 0-103, test indices 104-516
events:   99 test incidents
models:   30, three representations x ten seeds
seeds:    20261116-20261125
```

r5.2 has no separate validation interval. Only test inference is reported.

Because the user count is twice r4.2's, base steps were doubled:

```text
floor(2000 / 16) * 10 = 1250
```

The coverage batches use the same 80% target and fixed batch size 16.

The fixed joint method detects 13.0 more test events than the official plain
baseline and 10.6 more than official PAI.

## 3. Primary locked tests

All tests are paired across the same ten seeds. Holm correction covers the four
pre-declared endpoints.

| Comparison | Metric | Mean delta | 95% seed CI | Positive seeds | Holm p |
| --- | --- | ---: | ---: | ---: | ---: |
| Joint vs official plain | PR-AUC | +0.002138 | [+0.001820, +0.002457] | 10/10 | 3.03e-7 |
| Joint vs official plain | K=10 event recall | +0.131313 | [+0.097421, +0.165205] | 10/10 | 1.06e-5 |
| Coverage effect under PAI | PR-AUC | +0.001504 | [+0.001151, +0.001857] | 10/10 | 9.76e-6 |
| Coverage effect under PAI | K=10 event recall | +0.144444 | [+0.126404, +0.162485] | 10/10 | 8.69e-8 |

All four endpoints pass Holm, with every seed in the same direction.

## 4. Consistency with r4.2

| Endpoint | r4.2 delta | r5.2 delta |
| --- | ---: | ---: |
| Joint vs official plain, PR-AUC | +0.005490 | +0.002138 |
| Joint vs official plain, K=10 | +0.108333 | +0.131313 |
| Coverage under PAI, PR-AUC | +0.002505 | +0.001504 |
| Coverage under PAI, K=10 | +0.050000 | +0.144444 |

The effect magnitudes differ by version, but all four directions agree.

The batch-only result also agrees: `A0-matched + PAI-A1` is worse than
`A0-official + PAI-A1` on PR-AUC and K=10. The positive mechanism is therefore
the interaction between coverage-aware batches and soft instance supervision,
not coverage batch replacement alone.

## 5. Current conclusion

Supported:

1. The r4.2 positive result replicates on r5.2 under the locked matrix.
2. The final method improves point-level ranking and canonical fixed-budget
   event recall over the standard official baseline.
3. Coverage-aware soft training adds an independent positive increment over
   `A0-matched + PAI-A1`.
4. The direction is stable across two CERT versions and ten seeds per version.

Not supported:

1. r5.2 is a seen version replication, not external confirmation.
2. It does not establish transfer to CLUE-LDS, SMD, or other domains.
3. It does not establish independent relation-channel benefit.
