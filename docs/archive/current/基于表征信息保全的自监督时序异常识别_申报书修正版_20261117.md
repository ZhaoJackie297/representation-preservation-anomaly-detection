## 一、项目定位与导师方向对应

### 1.1 项目定位

本项目研究无异常标签条件下的用户行为表示学习与异常检测。项目以 TS2Vec 为基础，围绕一个统一问题展开：

> 通用时序对比学习在训练端会把相似正常行为错误地推开，在打分端又会丢失表征的径向幅度信息；两端共同造成异常信息损失。

为此，本项目提出“表征信息保全”主线：

1. 训练端使用 SoftCLT 软对比，减少正常行为之间的假负样本；
2. 打分端比较余弦与欧氏表征库，优先保留尺度/幅度信息；
3. 在 CERT 的多版本和 SMD 上做同划分、同预算、同随机种子的外部审计。

本项目不声称发明 SoftCLT、PAI 或 TS2Vec 的基础算法。创新定位为：

> 面向用户行为数据的方法适配、统一机制解释、严格对照实验与可复现技术实现。

## 二、研究背景与问题

互联网用户行为具有连续、情境依赖和群体关联特征。异常既可能是一次行为突变，也可能是短期上下文偏离。实际系统通常缺乏可靠异常标签，无法直接训练监督分类器。

TS2Vec 通过重叠裁片、实例级对比、时间级对比和层次池化学习时序表示。但其基本假设与用户行为存在两个错位。

### 2.1 正常类碰撞

实例对比通常把同一 batch 中其他实例都当作负样本。CERT 中不同正常用户、同一用户不同日期的行为可能非常相似。若直接推开这些样本，会破坏正常行为邻域，产生假负样本和类碰撞。

SoftCLT 用数据空间距离生成软正权重：

\[
w_I(u,v)=
\frac{2\alpha}
{1+\exp(\tau_I D_{uv})}
(1-\alpha)\mathbf 1[u=v]
\]

距离越近，正关系权重越高。

### 2.2 幅度信息丢失

用户异常经常表现为同类行为强度的显著变化，例如文件复制从个位数增加到数百次。余弦距离只比较方向，忽略表征长度。欧氏距离同时保留方向和尺度，是检验幅度信息是否丢失的最直接诊断。

本项目先检验“余弦→欧氏”，再探索 magG/T2 辅助项，不预设完整加权公式必然有效。

## 三、研究目标

1. 构建不依赖异常标签的 CERT 用户日时序数据；
2. 在 TS2Vec 实例对比中实现 CERT 适配的 SoftCLT；
3. 构造训练期 47 维用户画像距离，并验证其时间稳定性；
4. 比较原始 mask、余弦库、欧氏库和 PAI 评分；
5. 在 CERT r4.2、r5.2、r6.2 和 SMD 上做外部审计；
6. 明确区分点级排序、固定 K 事件召回和五事件压力测试；
7. 对失败结果和证据边界进行保留。

## 四、研究内容

### 4.1 用户行为数据构建

原始数据包括登录、设备、文件、邮件和网页访问。项目按用户和日期聚合为 27 维序列，其中：

- 20 维登录、设备、文件、邮件、HTTP 计数；
- 3 维首次登录、最后登出和活跃跨度；
- 4 维活跃、周末和周期日历信息。

训练期标准化只使用训练数据。恶意用户、恶意日期和场景答案单独保存，只用于评价。

### 4.2 表征信息保全训练端

在 TS2Vec 实例和时间对比中引入 SoftCLT：

\[
\mathcal L=
\lambda_I\mathcal L_I^{soft}
(1-\lambda_I)\mathcal L_T^{soft}
\]

固定：

```text
lambda = 0.5
tau_temp = 1.5
alpha = 0.5
epochs = 10
batch_size = 16
```

设置：

- T0：Native TS2Vec；
- T2：仅 temporal-soft；
- T3：instance-soft + temporal-hard；
- T4：instance-soft + temporal-soft。

### 4.3 CERT 47 维画像距离

用户训练期画像：

\[
\phi_u=
\left[
\operatorname{median}_{k}(x_{u,k}),
q_{90,k}(x_{u,k}),
\operatorname{active\_fraction}_u
\right]_{k=1}^{23}
\]

23 个特征包含 20 个计数特征及 3 个时间特征。逐维跨用户标准化后：

\[
D_{uv}=\|\tilde\phi_u-\tilde\phi_v\|_2
\]

SoftCLT 带宽由训练期距离中位数决定：

\[
\tau_I=
\frac1{\operatorname{median}_{u<v}(D_{uv})}
\]

选择画像距离而非 DTW 的原因：

1. CERT 用户日序列高维稀疏，DTW 会把缺失、不活跃和真实零行为混入对齐路径；
2. 1000–4000 名用户两两 DTW 成本过高；
3. 画像保留典型强度、尾部强度、时间习惯和活跃持续性。

该距离不等价于 DTW，是明确的 CERT 适配假设。

### 4.4 打分端信息保全

对同一表征库比较：

1. 原始 mask L1；
2. 余弦最近邻距离；
3. 欧氏最近邻距离；
4. 欧氏 + magG + T2 的 PAI。

\[
S_{PAI,A1}^{project}=
z_{euc}+0.6z_G+0.4z_{T_2}
\]

项目使用的相对权重是 `1.0:0.6:0.4`。官方 PAI 代码的标量权重为 `0.6:0.4:0.2`；两者只改变已冻结组件的融合权重。报告另列官方权重敏感性，不在测试集上择优。E0/E1 的 `S5_pai_full_global` 是 A3（通道 max 后取 top-2 均值），不是 A1（通道 max 后取均值），不得混写。

### 4.5 评价协议

- 点级：PR-AUC、ROC-AUC；
- 固定预算：Recall@K，K∈{5,10,20}，7 天冷却；
- 事件：威胁实例是否被命中；
- 多种子：20261116、20261117、20261118；
- r6.2：5 个威胁实例、78 个恶意账户日；
- SMD：28 台机器。

## 五、已完成实验与结果

### 5.1 47 维画像构造效度

训练期前后两半距离矩阵的 Spearman 相关：

| 数据 | 距离矩阵稳定性 | 41 维 Top-10 重合率 | 47 维 Top-10 重合率 |
| --- | ---: | ---: | ---: |
| r4.2 | 0.978 | 0.640 | **0.700** |
| r5.2 | 0.965 | 0.534 | **0.625** |
| r6.2 | 0.958 | 0.317 | **0.422** |

结论：画像距离具有时间稳定性，加入 3 个时间特征后正常邻居关系更稳定。

### 5.2 instance-soft 机制

| 模型 | Top-10 邻域一致率 | 局部距离秩相关 | 有效秩 |
| --- | ---: | ---: | ---: |
| T0 | 0.390 | 0.440 | 8.88 |
| T3 | **0.498** | **0.503** | **14.70** |
| T4 | **0.495** | **0.493** | **14.37** |

instance-soft 确实改善了正常邻域结构和有效秩。temporal-only 则下降，temporal-soft 相对 instance-soft 没有稳定额外收益。

从表示几何看，instance-soft 把正样本权重改写为行为画像距离的核：

\[
w^I_{u,v}=\frac{2\alpha}{1+\exp(\tau_I d^X_{u,v})}
\]

它在不同用户之间加入“内容相关的弱正边”，修复标准 instance 对比把相似正常用户当作负样本的问题。因此其预期效果是同时提高数据邻域保持和有效秩，而不是单纯把表示压到低维。

temporal-soft 的图则只由时间索引差决定：

\[
w^T_{t,s}=\frac{2}{1+\exp(\tau_T\,2^d|t-s|)}
\]

它是用户内的平移不变时间平滑先验，不包含跨用户语义。CERT 中相邻日期可能分别属于正常工作日、异常起点、休假或持续异常段；异常也可能在时间上是平滑的。因此 temporal-soft 无法替代跨用户 instance 对比。三 seed 谱实验显示，T1→T2 的 temporal Dirichlet energy 下降 `0.1098`，时间高频残差 ROC 上升 `0.0642`；T3→T4 的时间残差 ROC 也上升 `0.0066`，但 instance residual、kNN overlap、有效秩和最终 PR/ROC 没有同步改善。结论应写成“局部时间平滑效应存在，但未形成端到端独立增量”。

## 六、创新点

### 6.1 表征信息保全的统一机制

项目把训练端正常关系破坏与打分端幅度丢失统一解释为“信息保全不足”，并通过关闭软权重、替换距离度量、固定预算和外部版本验证该机制。创新点不是把两个现成方法并列，而是要求两端实验能够分别解释同一类信息损失。

### 6.2 面向 CERT 的 47 维画像距离与构造效度

项目使用训练期 23 个非日历行为特征的 median、q90 和活跃比例构造 47 维用户画像，以对角标准化欧氏距离生成 SoftCLT 软权重。该距离不使用标签，并通过前后半段距离稳定性和 Top-10 邻域重合率验证其构造效度。

该点属于 CERT 适配与验证创新，不声称替代 DTW。

### 6.3 同协议联合审计与证据边界

项目为 r6.2 增加同 1000 用户子集的 T0 对照，为 SMD 增加同 512 点窗口的 T0 对照，并把点级排序、固定预算和事件命中分开报告。该设计避免把训练子集、窗口长度或评价阈值变化误归因于 SoftCLT。

## 七、实验有效性控制

1. 标签不进入训练、距离、带宽和阈值；
2. r5.2、r6.2 重新训练并冻结；
3. 距离、alpha、lambda 和 tau 均由训练期或公开配置固定；
4. 测试期只评价，不重新调参；
5. r6.2 与 SMD 均补齐匹配 T0；
6. 报告 3 个随机种子；
7. 保留失败和负结果；
8. 不根据测试结果事后选择 magG/T2 权重。

## 八、主要风险与限制

| 风险 | 当前处理 |
| --- | --- |
| CERT 是合成数据 | 使用 r4.2/r5.2/r6.2 和 SMD 外部验证，不外推到真实企业 |
| SoftCLT 原本不是为用户日志设计 | 明确画像距离是适配假设，不声称等价 DTW |
| T4 与 T3 差异很小 | 不写 temporal-soft 已证明有效 |
| PAI 组件不稳定 | 主贡献只写欧氏诊断，magG/T2 作辅助探索 |
| r6.2 仅 5 个事件 | 只作压力审计，不作确认性外部结论 |
| SMD 只有一个 seed | 28 台配对统计仍标为初步外部支持 |
| 三个种子下 Wilcoxon 分辨率有限 | 报告方向一致性，不伪造显著性 |

## 十、最终陈述

本项目当前完成的是一项针对 TS2Vec 的信息保全方法组合、CERT 适配和严格审计工作。实验结果支持 instance-soft 改善正常邻域结构、完整 SoftCLT 在两个 CERT 版本上改善联合排序，并在 SMD 上产生轻微外部增量；同时明确保留 temporal-only 失败、magG/T2 不稳定、r6.2 五事件审计不足等边界。

新增 iForest 外部对照后，T4+PAI-A1 在 CERT r4.2 的点级排序和固定预算事件命中上均高于该经典表格基线；iForest 与 Native TS2Vec 接近的结果同时说明，双端优化的收益不能仅归因于采用了时序模型。

项目不把“方法组合”包装成新基础算法，也不把未完成结果写成成功结论。
