# Temporal-soft 桥接：可验证的中间层解释

日期：2026-11-19

## 1. 两层正样本图

对一个用户日样本 `x_{u,t}`，编码器输出：

```text
z_{u,t} = f_theta(x_{u,t})
```

SoftCLT 同时使用两类正样本图：

```text
G_I: 跨用户、由行为相似度定义
G_T: 用户内部、由时间间隔定义
```

instance-soft 改变的是“哪个用户属于同一个正常语义邻域”。temporal-soft
改变的是“同一用户相邻时间位置需要多接近”。它们不是同一种平滑：

- instance-soft 提供跨用户语义邻接，能够恢复共享正常流形；
- temporal-soft 是用户内低通算子，只压缩时间轨迹的高频变化。

## 2. 与异常信号的关系

设用户内时间图为 `G_T`，其归一化 Dirichlet 能量为：

```text
E_T(Z) = sum_{t,s} W^T_{t,s} ||z_t - z_s||^2
```

temporal-soft 增加相近时间点的权重，因此倾向降低 `E_T`。这会产生两个
相反后果：

1. 对持续漂移，平滑后的轨迹更容易与正常轨迹形成稳定差异；
2. 对单日尖峰，平滑会压低高频方向，可能削弱点级异常。

所以不应假设 temporal-soft 普遍有益。可检验预测是：

```text
H1: T4 相对 T3 在缓慢漂移/持续偏移上改善表示分数。
H2: T4 相对 T3 不一定改善孤立点尖峰，甚至可能降低固定 K 事件召回。
H3: 时间高频可分性提高，不等于最终表征库的 PR-AUC 或 K=10 提高。
```

## 3. 受控实验映射

实验固定 `T3 -> T4` 为唯一训练变化，并在相同真实正常序列上注入四类事件：

```text
point / sustained / drift / switch
```

三种强度使用 `0.5 / 1.0 / 2.0`，三种子为
`20261116 / 20261117 / 20261118`。

主要结果：

- 全部 12 个信号-强度设置的 T4-T3 PR-AUC 差值为正，10/12 个设置为
  3/3 seeds 同向；
- 在 `drift=2.0` 上，T4-T3 的 PR-AUC 为 `+0.022430`，3/3 seeds 正向；
- 在 `sustained=2.0` 上，PR-AUC 为 `+0.076616`，3/3 seeds 正向；
- 在 `point=2.0` 上，PR-AUC 为 `+0.067190`，但 K=10 为 `-0.013889`；
- 12 个设置中只有 3 个 K=10 差值为正，固定预算收益明显弱于点级排序；
- 在 `drift` 和 `sustained` 上，K=10 已接近饱和，无法观察额外事件收益。

因此当前最稳妥的表述是：

> instance-soft 建立跨用户语义邻接；temporal-soft 在此基础上提供时间低通
> 先验。受控数据支持它对持续信号的表示几何有作用，但没有证明它对固定预算
> 事件检测有稳定增量。

## 4. 不能写的结论

- 不能写“temporal-soft 全面有效”；
- 不能写“temporal-soft 对时序异常无效”；
- 不能把 PR-AUC 的局部提高等同于 K=10 事件召回提高；
- 不能用当前受控注入替代真实 CLUE-LDS 测试。
