# SoftCLT 作用机制的数学分析与实验验证

日期：2026-11-17  
定位：计算机研究生普通水平的数学机制分析 + 已有实验复核  
研究问题：为什么 instance-soft 有效，而 temporal-soft 没有独立的端到端收益？

## 一、问题定义

TS2Vec 的层级对比损失写成：

\[
\mathcal L
=
\lambda\mathcal L_{\mathrm{inst}}
+
(1-\lambda)\mathcal L_{\mathrm{temp}}.
\]

SoftCLT 的作用不是改变编码器结构，而是改变正样本的权重。本文只比较五组模型：

| 模型 | instance 项 | temporal 项 | \(\lambda\) |
| --- | --- | --- | ---: |
| T0 | hard | hard | 0.5 |
| T1 | 无 | hard | 0.0 |
| T2 | 无 | soft | 0.0 |
| T3 | soft | hard | 0.5 |
| T4 | soft | soft | 0.5 |

因此有三组有效对照：

- `T0→T3`：只改变 instance 正样本权重；
- `T1→T2`：只改变 temporal 正样本权重；
- `T3→T4`：在 instance-soft 上加入 temporal-soft。

不能直接用 `T2 vs T0` 判断 temporal-soft 的作用，因为它同时移除了 instance 对比项。

## 二、加权 InfoNCE 的重心更新

对一个表示 \(z_i\)，设与其他样本的归一化点积相似度为：

\[
s_{ij}
=
\frac{z_i^\top z_j}{\tau},
\qquad
p_{ij}
=
\frac{\exp(s_{ij})}
{\sum_k\exp(s_{ik})}.
\]

加入正样本权重 \(w_{ij}\) 后，锚点损失为：

\[
\mathcal L_i
=
-\sum_jw_{ij}\log p_{ij}.
\]

**命题 1.** 若正样本权重 \(w_{ij}\) 由外部数据生成、在当前优化步中视为常数，且相似度采用归一化点积，则

\[
\nabla_{z_i}\mathcal L_i
=
\frac{1}{\tau}
\left[
\sum_k p_{ik}z_k
-
\frac{\sum_jw_{ij}z_j}
{\sum_jw_{ij}}
\right].
\]

因此一次梯度下降会令表示向软正样本加权重心移动：

\[
z_i
\leftarrow
z_i
+
\eta
\left(
\frac{\sum_jw_{ij}z_j}{\sum_jw_{ij}}
-
\sum_k p_{ik}z_k
\right).
\]

**简证.** 对单个正样本 \(j\)，

\[
\frac{\partial}{\partial z_i}
\left(-\log p_{ij}\right)
=
\frac{1}{\tau}
\left(
z_j-\sum_kp_{ik}z_k
\right).
\]

对全部正样本按 \(w_{ij}\) 加权求和，得到

\[
\nabla_{z_i}\mathcal L_i
=
\frac{1}{\tau}
\left[
\left(\sum_jw_{ij}\right)
\sum_kp_{ik}z_k
-
\sum_jw_{ij}z_j
\right].
\]

两边除以 \(\sum_jw_{ij}\) 即得命题 1。

该结果给出两个直接推论：

1. instance-soft 用行为画像距离定义 \(w^I_{u,v}\)，因此改变的是跨用户正样本重心；
2. temporal-soft 用时间距离定义 \(w^T_{t,s}\)，因此改变的是用户内时间正样本重心。

这个结果说明：

- \(w_{ij}\) 不是普通温度，而是决定了表示被拉向哪一类样本；
- instance-soft 决定“哪些不同用户可以被视为相似”；
- temporal-soft 决定“同一用户哪些时间位置可以互相靠近”。

## 三、两类软权重的含义

### 3.1 instance-soft

\[
w^I_{u,v}
=
\frac{2\alpha}
{1+\exp(\tau_I d^X_{u,v})}.
\]

权重由训练期 47 维用户画像距离决定。

标准 instance 对比只把同一用户的两个增强视图作为正样本，其他用户全部作为负样本。这在用户行为数据中会产生假负例：行为相似但用户 ID 不同的正常用户被强行分开。

instance-soft 将行为相似用户加入弱正集，因此预期改善：

- 数据邻域与表示邻域的一致性；
- 正常行为流形的有效秩；
- 跨用户正常模式的共享。

### 3.2 temporal-soft

\[
w^T_{t,s}
=
\frac{2}
{1+\exp(\tau_T2^d|t-s|)}.
\]

权重只依赖时间索引差，不使用行为内容。

它的作用是让同一用户相邻日期的表示更接近，即一种时间平滑先验。它不能提供跨用户语义，也不能区分：

- 两个都是正常日；
- 正常日与异常起点；
- 两个持续异常日；
- 周末、休假和工作日。

因此 temporal-soft 只能改变用户内轨迹的平滑程度，不能代替 instance 对比恢复跨用户正常流形。

## 四、实验对照

### 4.1 三 seed 主结果

| 模型 | kNN overlap | 有效秩 | validation PR | test PR | validation ROC | test ROC |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| T0 | 0.3902 | 8.884 | 0.014371 | 0.007447 | 0.8093 | 0.8161 |
| T1 | 0.2601 | 5.110 | 0.011258 | 0.005496 | 0.7558 | 0.7593 |
| T2 | 0.2149 | 7.669 | 0.012622 | 0.006252 | 0.7716 | 0.7722 |
| T3 | **0.4977** | **14.696** | **0.016950** | **0.008922** | **0.8355** | **0.8421** |
| T4 | 0.4952 | 14.375 | 0.016754 | 0.008867 | 0.8341 | 0.8416 |

### 4.2 结果解释

1. `T0→T3` 同时提高了 kNN overlap、有效秩和点级指标，说明 instance-soft 的主要作用是改善内容相关的正常邻域。
2. `T1→T2` 说明 temporal-soft 比 hard temporal 略好，但因为没有 instance 项，仍明显低于 T0/T3。时间平滑不能替代跨用户对比。
3. `T3→T4` 只增加 temporal-soft，但 PR、ROC、kNN 和有效秩均轻微下降，说明 temporal-soft 没有形成独立端到端收益。

三 seed 平均效应量：

| 对比 | Δ test PR-AUC | Δ test ROC-AUC | Δ kNN overlap | Δ 有效秩 |
| --- | ---: | ---: | ---: | ---: |
| T3−T0 | +0.001475 | +0.026020 | +0.107517 | +5.812230 |
| T2−T1 | +0.000756 | +0.012833 | -0.045250 | +2.558949 |
| T4−T3 | -0.000055 | -0.000539 | -0.002533 | -0.321008 |

由于只有 3 个训练 seed，上表只用于报告效应方向与幅度，不用于宣称统计显著。

### 4.3 补充谱诊断

为了确认 temporal-soft 是否确实产生时间平滑，计算时间图的归一化 Dirichlet 能量：

\[
R_T(Z)
=
\frac{\operatorname{tr}(Z^\top L_TZ)}
{\operatorname{tr}(Z^\top D_TZ)}.
\]

| 对比 | Δ temporal Dirichlet | Δ temporal residual ROC |
| --- | ---: | ---: |
| T1→T2 | -0.1098 | +0.0642 |
| T3→T4 | -0.00565 | +0.00660 |

这说明 temporal-soft 并非完全无效，它确实降低了用户内时间变化，并提高了时间高频残差的单独可分性。但该局部收益没有转化为最终表征库评分的稳定提升。

另外，T3 的 instance Dirichlet energy 反而高于 T0，却获得更高的 kNN overlap 和残差 AUC。因此 instance-soft 不能简单解释为“降低图能量”，更准确的说法是：

> instance-soft 重新校准了内容相关的正样本重心，使表示邻域更符合数据中的正常行为关系。

## 五、结论

本文得到三个结论：

1. 加权 InfoNCE 使表示向软正样本加权重心靠近；
2. instance-soft 通过内容相关的跨用户权重修复假负例，因此改善正常表示邻域；
3. temporal-soft 是用户内时间平滑先验，具有局部低通效果，但既不能替代 instance 对比，也没有在 instance-soft 之上形成稳定的端到端收益。

最终表述：

> instance-soft 的有效性来自内容相关的语义邻接，而不是单纯的低通平滑；temporal-soft 的有效范围受异常形态和时间语义约束，在当前 CERT 日粒度任务中只表现出局部时间平滑收益。

## 六、边界

- 只有 3 个训练 seed，不能把 3/3 方向一致写成统计显著；
- r6.2 只有 5 个威胁事件；
- temporal-soft 对缓慢漂移任务是否有效仍需单独实验；
- 当前结论限定于 CERT 日粒度、当前窗口和当前异常评价协议。
