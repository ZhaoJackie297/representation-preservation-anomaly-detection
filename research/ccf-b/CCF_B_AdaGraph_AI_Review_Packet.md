## 研究问题

TS2Vec 的硬实例对比会把行为相近的正常用户当作负样本。固定 47 维画像距离只能提供静态规则，无法随表示学习调整；纯表示近邻图又会自我强化。

本文研究的问题是：

> 能否用稳定画像先验约束表示反馈，在有限信任域内学习用户软关系图，从而降低假负样本偏差，同时避免异常用户被吸收到正常表示核心？

## 方法：AdaGraph-SoftCLT

### 1. 画像先验

用训练期 47 维鲁棒画像构造用户关系先验 `P`。画像只使用行为和时间特征，不使用 LDAP 部门、角色或团队字段。

### 2. EMA 表示距离

用第一阶段模型的 EMA 教师表示计算用户距离，并对 EMA 表示停止梯度。距离按行中位数归一化：

```text
d_tilde(u,v) = d_EMA(u,v) / median_{v != u} d_EMA(u,v)
```

若行中位数过小，使用预先定义的数值下限，避免温度失效。

### 3. 支撑集

对每个用户 `u`，按以下分数选择 top-m 邻居：

```text
score(u,v) = P(u,v) * exp(-d_tilde(u,v) / tau)
```

在选出的支撑集 `S_m(u)` 上，将画像先验 `P` 重新归一化为 `P_m`。所有 KL 计算都在该支撑集上完成。

### 4. 信任域更新

对每个用户行求解：

```text
min_{W in simplex} <W, d_tilde> - tau * H(W)
s.t. KL(W || P_m) <= epsilon
```

在支撑集上得到：

```text
W_beta(u,v) ∝ P_m(u,v)^beta *
               exp(-(1 - beta) * d_tilde(u,v) / tau)
beta = lambda / (tau + lambda), 0 <= beta < 1
```

KL(W || P_m) 随 beta 单调下降。二分搜索 beta，使其满足 KL 上界；如果 beta=0 已满足约束，则直接取 beta=0。

- `beta=0` 表示纯表示图；
- `beta` 增大表示更多保留画像先验；
- `beta` 接近 1 时回到画像图。

行熵已经由目标中的 `tau * H(W)` 控制，不再额外增加行熵约束。行熵只作为监控指标。

### 5. 两轮更新

- A1：固定画像图，训练 `B` 个优化步。
- A3：画像图训练 `B` 步，更新一次图，再从当前权重继续训练 `B` 步。
- A4：在 A3 基础上再更新一次图，从当前权重继续训练 `B` 步。
- A1+：固定画像图连续训练到与 A3 或 A4 相同的总步数。
- A9：固定画像图，按与 A4 相同的三段预算继续训练，但图不更新。

所有阶段重置优化器状态，并采用同一种按阶段缩放的 warmup-cosine 调度。A1+ 使用与总训练预算对应的单一 warmup-cosine 调度。

## 与已有工作的区别

- SoftCLT：实例距离固定，来自原始数据空间。
- NNCLR：用当前表示支持集最近邻构造正样本，没有画像锚。
- PCL、SwAV：依赖原型或聚类分配。
- Incremental False Negative Detection、False Negative Cancellation：动态检测或抵消假负样本，没有稳定用户先验和信任域约束。
- TGMC 等图对比内部威胁方法：构造异构图和专用图编码器；AdaGraph 只校正 TS2Vec 训练中的实例软权重。

AdaGraph 的新颖性必须限定为：

> 画像锚定、EMA 表示反馈和 KL 信任域约束下的实例软权重图学习。

不能宣称首次将图或对比学习用于内部威胁检测。

## 理论目标

当前 Proposition 1 只是标准加权 InfoNCE 梯度。B 类版本至少需要：

1. 将 InfoNCE 梯度分解为真负样本、假负样本和正样本；
2. 给出假负样本偏差与错误软权重之间的上界；
3. 给出 KL 信任域下表示图相对画像图的漂移界；
4. 给出 AdaGraph 优于固定画像图和纯表示图的条件。

## 1. 研究假设

- H1：画像先验锚定的信任域图比固定 47 维画像图更能降低假负样本偏差。
- H2：画像锚、EMA 教师和 KL 信任域分别对稳定性或预测性能有独立作用。
- H3：AdaGraph 的收益不能由更长训练、重复初始化或图稀疏加权解释。
- H4：训练端图校正与打分端欧氏库存在可检验的互补关系。
- H5：AdaGraph 在固定预算、low-and-slow 和原始行为通道扰动下保持运营可用性。

## 2. 训练变体

| 编号 | 定义 | 主要作用 |
| --- | --- | --- |
| A0 | TS2Vec 硬实例负样本 | 原始编码器参照 |
| A1 | 固定 47 维画像软权重，单阶段训练 | R0 主基线 |
| A1+ | 固定画像图，连续训练到指定对照预算 | 等算力对照 |
| A2 | 当前表示图，无 EMA、无画像锚、无信任域，单阶段 `B` | 已有近邻图式路线 |
| A3 | 画像锚 + EMA + 信任域的一次更新 | AdaGraph 单轮核心 |
| A4 | AdaGraph 最多两轮更新 | 主候选方法 |
| A3-noAnchor | `beta=0`，EMA 表示图，top-m 按表示距离选择 | 检验画像锚 |
| A3-noEMA | 画像锚 + 当前表示 + 信任域 | 检验 EMA 教师 |
| A3-noTrust | `P_m * exp(-d_tilde/tau)`，不满足 KL 的缩放解 | 检验信任域 |
| A3-hard | 按融合分数选 top-m，正关系取 1，其余负关系取 0 | 检验软权重形式 |
| A5a | 度保持随机图 | 排除稀疏加权 |
| A5b | `P_perm(u,v)=P(pi(u),pi(v))`，pi 为固定随机置换 | 检验关系信息本身 |
| A6 | 仅画像中位数维度 | 画像构造消融，放附录 |
| A7 | NNCLR 式近邻正样本 | 近邻对比基线 |
| A8a | Incremental False Negative Detection 适配 | 假负检测基线 |
| A8b | False Negative Cancellation 适配 | 假负抵消基线 |
| A9 | 固定画像图，按 A4 相同轮数启用权重续训但图不更新 | 排除重复训练与重启收益 |

A2 与 A3-noAnchor 的区别：A2 使用当前模型的普通表示并只训练 `B`；A3-noAnchor 使用 EMA 教师、top-m 稀疏和 `2B` 两阶段训练，并令 `beta=0`。

A3-hard 与 A7 的区别：A3-hard 只把 AdaGraph 软图改为硬近邻筛选，仍使用画像和 EMA 支撑集；A7 使用 NNCLR 支持集近邻作为额外正样本，不使用画像图。

### 训练预算口径

- 以总优化步数而不是 epoch 名称作为预算单位。
- A1 的基础预算记为 `B`。
- A3 为 `2B`，A1+ 在 H1 比较中使用连续 `2B`。
- A4 为 `3B`，A1+ 在 H2 比较中使用连续 `3B`。
- A4 后两段均从上一阶段权重继续训练，并在每段开始时重置优化器状态。
- A9 使用相同的三段 `1B` 权重续训和优化器重置，但图始终固定。
- A1+ 使用与总预算匹配的连续 warmup-cosine 调度；A3/A4/A9 使用等比例的分段调度。
- A7、A8a、A8b 与对应主比较变体使用相同搜索空间、最大试验次数和总步数。

## 5. 成功与失败规则

预注册 `10` 个种子，不做“5 个不够再扩到 10 个”的事后决定。

主推断方案：

1. 对每个种子计算主终点差值；
2. 先对 10 个种子求配对平均；
3. 再以用户为聚类单位做 10,000 次配对 bootstrap；
4. 事件级 bootstrap 仅作敏感性分析；
5. Wilcoxon 符号秩检验和 8/10 种子方向一致性作为稳健性结果，不替代用户聚类 bootstrap。

机制非劣界：

- Top-10 邻域一致率配对差值的 95% CI 下界不得低于 `-0.02`；
- 有效秩配对差值的 95% CI 下界不得低于 `-0.50`；
- 组织结构参照一致性只报告效应量与置信区间，不设为强制门槛。

方法被认定为通过 Gate 1，需要同时满足：

- 两个数据集上，两个共同主终点平均配对差值均大于 0；
- 每个数据集、每个主终点至少 8/10 种子方向一致；
- A4 在确认性比较家族经 Holm 校正后至少有一个主终点显著；
- 机制指标满足上述非劣界；
- A4 相对 A1+、A9、A7、A8b 至少在一个共同主终点上保留正向效应。

若 r4.2 或 r5.2 任一共同主终点平均方向为负，停止 B 类主方法声明。

## 6. Bootstrap

- 主分析单位：用户。对用户进行有放回重采样，并保留该用户全部日期和事件。
- 敏感性分析：事件级 bootstrap。
- 重复次数：10,000。
- PR-AUC 与事件召回应分别计算配对差值的 95% 百分位置信区间。
- 不把用户日作为独立单位，避免低估稀疏行为数据的相关性。

- 主参照：同部门且同角色；

## 8. 冻结参数范围

- EMA decay：`{0.99, 0.995, 0.999}`；
- 归一化距离温度 `tau`：`{0.05, 0.1, 0.2, 0.5, 1.0}`；
- KL 上界 `epsilon`：`{0.01, 0.05, 0.1, 0.2}`；
- top-m：`{10, 20, 50}`；
- 学习率与 weight decay 使用与 A1 相同的搜索空间；
- A1+ 与 A4 使用相同数量的学习率调度候选。

## 9. 批次与排除

### 第一批 pilot

r4.2，1–2 个种子：A1、A1+、A3、A5a、A5b、A7。

### 第二批

Gate 1 pilot 有信号后，10 种子并扩展到 r5.2：A2、A4、A8a、A8b、A9 和 A3 消融。

### 第三批

Gate 1 通过后：深度基线、S 系列交叉、统计检验、安全实验。

排除规则：

- r6.2 不进入显著性检验；
- CERT r1 在完成标签与处理口径审计前不使用；
- SMD 只进入 S 系列和检测基线；
- PSM/SMAP/MSL 不用于 AdaGraph 用户图结论；
- 不含标签的失败运行和 OOM 记录保留，不进入性能主表；
- 不用测试期事件决定 epoch、α、τ、β、top-m 或早停。

A7、A8a、A8b 与 A4 使用相同的最大调参试验次数，并只在 r4.2 的训练期内部验证上选参；锁定后直接迁移到 r5.2。

## 10. 标签隔离

训练期早停只允许使用：

- 训练损失；
- 训练期内部验证损失；
- 有效秩；
- 各向同性；
- 图边变化率和 KL 漂移。

“异常用户进入正常核心比例”需要测试标签，只能作事后诊断，不能触发早停。

## A. 训练端方法实验

| 代号 | 实例关系来源 | 作用 |
| --- | --- | --- |
| A0 | 硬实例负样本 | TS2Vec 原始参照 |
| A1 | 47 维画像距离软权重 | 当前 R0 主方法 |
| A1+ | 固定画像图，连续训练到指定对照预算 | 等算力对照 |
| A2 | 当前表示图，无 EMA、无画像锚、无信任域，单阶段 `B` | 表示空间图对照 |
| A3 | 画像锚 + EMA + KL 信任域的一次更新 | AdaGraph 单轮核心 |
| A4 | AdaGraph 最多两轮更新 | 主候选方法 |
| A3-noAnchor | `beta=0`，EMA 图，top-m 按表示距离选择 | 检验画像锚 |
| A3-noEMA | 用当前表示替代 EMA 教师 | 检验 EMA |
| A3-noTrust | `P_m * exp(-d_tilde/tau)`，不满足 KL 的缩放解 | 检验信任域 |
| A3-hard | 按融合分数选 top-m，正关系为 1，其余负关系为 0 | 检验软权重 |
| A5a | 随机图，保持度分布 | 排除稀疏加权 |
| A5b | `P_perm(u,v)=P(pi(u),pi(v))` | 检验关系信息本身 |
| A6 | 画像仅中位数维度 | 画像构造消融，放附录 |
| A7 | NNCLR 式近邻正样本 | 区分已有近邻对比学习 |
| A8a | Incremental False Negative Detection 适配 | 假负检测基线 |
| A8b | False Negative Cancellation 适配 | 假负抵消基线 |
| A9 | 固定画像图，按 A4 相同轮数启用权重续训 | 排除重复训练与调度收益 |

训练预算以总优化步数计算。A1 为 `B`；A3 与对应 A1+ 为 `2B`；A4、A9 与对应 A1+ 为 `3B`。A9 使用三段 `1B` 权重续训和逐段优化器重置，但图始终不更新。

A2 与 A3-noAnchor 的区别是：A2 使用当前普通表示和单阶段 `B`；A3-noAnchor 使用 EMA、top-m 和两阶段 `2B`。A3-hard 仍使用画像+EMA 支撑集，只是把软权重改为硬筛选，因此不同于 NNCLR 式 A7。

所有变体固定相同编码器结构、总优化步数、单步 batch size、随机种子和评价协议。A4 第一阶段模型的训练步数计入总预算。

A7、A8a、A8b 优先使用官方代码适配，并记录相对原论文的必要改动。三者与 AdaGraph 使用相同最大调参试验次数；若有官方默认配置，先按官方配置运行一次，再做同预算调参。

每轮图更新必须记录：

- 边变化率；
- 与固定画像图的重合率；
- 行熵；
- KL 漂移；
- 有效秩与表示各向同性；
- 异常用户进入高相似正常核心的比例，仅用于测试后的事后诊断。

训练期早停只能使用训练损失、训练期内部验证、有效秩、各向同性、边变化率和 KL 漂移。需要测试标签的指标不得参与训练或早停。

## B. 打分端实验

| 代号 | 表示库距离 | 用途 |
| --- | --- | --- |
| S0 | mask L1 | Native TS2Vec 官方分数 |
| S1 | 余弦表征库 | 方向距离基线 |
| S2 | 欧氏表征库 | 幅度保留主方法 |
| S3 | 欧氏库 + magG | 单点幅度消融 |

Gate 1 前只跑主交叉 `A1/A4 × S1/S2`，即四个单元：

| 训练端 | 打分端 |
| --- | --- |
| A1 | S1 余弦 |
| A1 | S2 欧氏 |
| A4 | S1 余弦 |
| A4 | S2 欧氏 |

RQ3 的主交互对比定义为：

```text
Delta_interaction =
  (M_A4_S2 - M_A4_S1) -
  (M_A1_S2 - M_A1_S1)
```

`Delta_interaction > 0` 表示欧氏打分在 AdaGraph 上的增量大于在固定画像图上的增量。Gate 1 通过后，再做 A1–A4 与 S0–S5 的完整交叉。

## E. 统计与复现

- 种子：直接预注册 `10` 个；
- 汇总：均值、标准差、配对差值和 95% 置信区间；
- 检验：Wilcoxon signed-rank 或配对 t 检验；
- 确认性比较家族：A4 vs A1、A4 vs A1+、A4 vs A7、A4 vs A8b、A4 vs A9；
- 多重比较：Holm 覆盖 5 个确认性比较 × 2 个共同主终点；其余比较标记为机制分析或探索性分析；
- 主推断：先对 10 个种子求配对平均，再按用户聚类做配对 bootstrap；
- Bootstrap 主单位：用户聚类重采样，保留该用户全部日期和事件；
- Bootstrap 敏感性分析：事件级重采样；
- Bootstrap 重复次数：至少 10,000 次；
- 结果冻结：每次训练写入不可覆盖的 `run_id`；
- 随机性：Python、NumPy、PyTorch、DataLoader 和图初始化均固定；
- 失败实验：保留在报告中，不按结果删实验。

## F. 安全与运营实验

### F1. Low-and-slow

使用相同总攻击量构造两条曲线：

- 单日一次性注入；
- 多日递增 low-and-slow。

比较余弦、欧氏和 T2 在以下指标上的变化：

- 首次命中延迟；
- K 条告警内的事件召回；
- 误报数量和误报持续时间。

### F2. 幅度与方向扰动

主实验只操纵原始行为通道。表示层扰动仅作敏感性分析，因为攻击者直接控制嵌入不符合部署威胁模型。

原始行为层扰动包括：

- 径向幅度缩放；
- 通道替换；
- 时间平移；
- 随机通道缺失。

表示层仅补充：

- 小幅方向旋转；
- 嵌入幅度缩放。

威胁模型必须明确攻击者是否：

- 知道特征定义和评分方向；
- 能修改单个行为通道或多个通道；
- 有每日总扰动预算；
- 能在训练后适应阈值。

规避实验输出“检测率—扰动强度”曲线，而不是只报告一个扰动点。

### F3. 运营成本

统计不同 K 下的：

- 每日审查条数；
- 有效告警率；
- 重复告警冷却节省量；
- 每发现一个真实事件的审查条数。

审查时间采用 `5`、`10`、`20` 分钟/条三档假设，并报告排序结论是否随假设改变。当前阶段没有可靠文献支持具体分钟数，因此论文必须明确标为场景假设，而不是实测运营数据。

### F4. 案例研究

案例选择规则在查看结果前固定：

- 成功案例：在 K=10 命中的事件中取官方事件编号最小者；
- 延迟案例：在 K=10 命中的事件中取首次命中延迟最大者；
- 失败案例：在 K=10 未命中的事件中取官方事件编号最小者。

至少选择这 3 个 CERT 事件，给出：

- 首次进入 Top-K 的日期；
- 命中前的主要行为通道；
- magG、T2、欧氏距离和证据视图；
- 冷启动或持续异常情况；
- 证据报告如何帮助人工复核。

如果事件数量不足，按事件编号顺序向后替补，并记录选择过程。案例正文必须说明漏报、延迟或证据误导的具体原因。

## 停止条件

以下任一情况出现时，暂停 B 组实验并回到方法层修正，不能靠增加论文篇幅掩盖：

- AdaGraph 只在 r4.2 有效，r5.2 复现失败；
- r5.2 在未重新调参时任一主指标方向为负；
- 收益来自随机图、图稀疏度或 NNCLR 式近邻；
- 10 种子中方向一致性低于 8/10；
- 机制指标改善但端到端指标持续下降；
- 深度基线在同一协议下无法公平运行；
- S4 无法生成可复核证据；
- low-and-slow 下固定预算告警完全失效且没有明确边界分析。

如果 AdaGraph 未通过，但画像稳定性、固定预算和证据审计依然完整，可以把论文转为“自监督异常检测的诊断框架与系统性实证研究”。这种版本可以继续冲 C，不能包装成 B 类新方法。

## 一、直接基础

### TS2Vec

TS2Vec 在增强后的上下文视图上进行层次化实例与时间对比，并学习时间戳级表示。它是本项目的主干编码器。已核实：Yue 等，AAAI 2022，arXiv:2106.10466。

### SoftCLT

SoftCLT 将硬 0/1 对比关系替换为 0 到 1 的软权重。实例项使用数据空间距离，时间项使用时间戳差；在异常检测配置中，原论文默认关闭 instance-soft，主要验证 temporal-soft。已核实：Lee、Park、Lee，ICLR 2024 Spotlight，arXiv:2312.16424。

与本项目的关系：AdaGraph 保留 SoftCLT 的软对比形式，但不固定实例距离。画像距离作为先验，表示反馈只能在信任域内更新关系图。

## 二、近邻、原型与聚类对比

### NNCLR

NNCLR 在表示空间的支持集中检索最近邻，并将最近邻作为额外正样本。已核实：Dwibedi 等，ICCV 2021，DOI:10.1109/ICCV48922.2021.00945。

区别：NNCLR 的正样本完全由当前表示决定；AdaGraph 的边由画像先验约束，EMA 表示只提供有限反馈。NNCLR 式近邻是本项目必须实现的基线。

### PCL

PCL 在 EM 框架下迭代聚类原型和对比表示，通过 ProtoNCE 将样本拉向原型。作者 Li、Zhou、Xiong、Hoi；OpenReview ID `KmykpuSrjcq`，ICLR 2021。

区别：PCL 学习簇原型，AdaGraph 不替换用户原型，而是校正用户对之间的正关系权重。

### SwAV

SwAV 通过交换视图的聚类分配进行自监督学习，并使用多裁剪增强。已核实：Caron 等，NeurIPS 2020，arXiv:2006.09882。

区别：SwAV 的聚类分配是训练目标核心；AdaGraph 的图只进入实例正关系权重，保留 TS2Vec 的层次对比结构。

### MoCo

MoCo 使用队列和动量编码器构造大而一致的负样本字典。已核实：He 等，CVPR 2020，arXiv:1911.05722。

区别：MoCo 关注负样本字典规模与一致性；AdaGraph 关注用户行为语义相似造成的假负样本，不以扩大字典为目标。

## 三、假负样本与去偏

### Incremental False Negative Detection

该方法在训练过程中逐步检测并显式移除以假负样本。已核实：Chen 等，ICLR 2022，arXiv:2106.03719。

区别：该方法主要依赖当前表示空间动态检测；AdaGraph 额外使用稳定画像先验，并限制图漂移。

### False Negative Cancellation

Huynh 等在 WACV 2022 提出 False Negative Cancellation，对潜在同类负样本进行识别和抵消；DOI:10.1109/WACV51458.2022.00106。

注意：文献中的 `False Negative Cancellation` 与 Chen 等的 `Incremental False Negative Detection` 是两项不同工作，引用时不能混写。

### Debiased Contrastive Learning

Chuang 等通过估计同类负样本比例修正 InfoNCE 偏差，并给出下游泛化界。已核实：NeurIPS 2020，arXiv:2007.00224。

区别：Debiased CL 通常估计全局或采样层面的负样本污染；AdaGraph 使用用户级画像先验和表示反馈构造局部软关系。

## 四、表示塌缩与无标签质量控制

### Dimensional Collapse

Jing 等指出，对比学习也可能发生维度塌缩，即表示仅占据低维子空间。已核实：ICLR 2022，arXiv:2110.09348。

AdaGraph 必须逐轮记录有效秩、各向同性和异常用户进入正常核心的比例，不能只观察训练损失。

### RankMe

RankMe 使用表示矩阵的有效秩作为无标签质量指标，并可辅助超参数选择。已核实：Garrido 等，ICML 2023，arXiv:2210.02885。

## 五、内部威胁检测

### CERT 与早期无监督方法

CERT 数据集由 Glasser 和 Lindauer 在 2013 年 IEEE Security and Privacy Workshops 的论文中介绍。Tuor 等在 2017 年 AAAI AICS workshop 使用结构化日志做无监督深度检测。Yuan 与 Wu 在 Computers & Security 2021 综述了内部威胁检测的挑战与机会。

### LAN

LAN 面向活动级实时内部威胁检测，同时学习活动序列内的时间依赖和跨序列关系，并处理审查预算和类别不平衡。已核实：Cai 等，IEEE TIFS 2024，DOI:10.1109/TIFS.2024.3488527。

区别：LAN 构造活动级图并做实时告警；AdaGraph 是日级自监督表示训练中的软正关系校正。

### Ripple2Detect

Ripple2Detect 关注基于语义相似学习的多步内部威胁证据检测。已核实：Liu 等，Computers & Security 2025，DOI:10.1016/j.cose.2025.104387。由于本次未取得摘要，不在正文中扩展其具体算法细节。

### ATHITD

ATHITD 是基于注意力时序异构图神经网络的内部威胁检测方法。已核实：Qi 等，Computers & Security 2025，DOI:10.1016/j.cose.2025.104587。由于本次未取得摘要，只作为近期图关系方法引用。

### Knowledge-Enhanced Prompt Contrastive Learning

Yu 等提出面向多源用户行为图的知识增强自对比框架，使用关系编码的多头注意力、子图采样、提示文本对齐、VAE 过滤和多分类。已核实：Yu 等，IJCNN 2025，DOI:10.1109/IJCNN64981.2025.11229300。

区别：该方法依赖知识提示和行为图编码器；AdaGraph 不生成文本提示，也不改变 TS2Vec 主干。

### TGMC

TGMC 将多源异构图、GAT+GRU、掩码重建和多视图对比学习用于内部用户行为异常检测。OpenAlex 记录：Yuan 等，2026；本次未取得 DOI 和正式卷期信息。

这是当前最接近的“图 + 对比学习”工作，必须在相关工作和方法差异中主动处理：

- TGMC 构造异构图并使用专用于异常检测的图编码器；
- AdaGraph 不新增图编码器，校正的是 TS2Vec 训练中的实例正关系权重；
- TGMC 采用多视图掩码对比；
- AdaGraph 使用画像先验、EMA 反馈和 KL 信任域，把图更新限制在稳定行为关系附近。

如果最终检索确认 TGMC 已正式发表且代码可用，应尽量加入实验对照；至少需要提供概念对照表。

## 六、评价规范

- Kim 等指出 point-adjust 会系统性高估事件级检测能力，建议使用更严格的评价和局部事件指标。已核实：AAAI 2022，DOI:10.1609/AAAI.V36I7.20680。
- Wu 与 Keogh 指出部分时序异常检测基准存在缺陷，可能制造虚假进展。已核实：IEEE TKDE，DOI:10.1109/TKDE.2021.3112126。
- Demšar 系统讨论多数据集、多分类器的统计比较。已核实：JMLR 2006，DOI:10.5555/1248547.1248548。

AdaGraph 实验应同时报告点级指标、固定预算事件命中、延迟和 bootstrap 置信区间，不依赖 point-adjust 作为主要证据。

## 七、相关工作可直接采用的段落骨架

时序自监督表示学习通过时间邻域、层次对比、软对比或聚类原型学习无标签表示。TS2Vec 通过层次化实例与时间对比获得时间戳级表示；SoftCLT 进一步用数据空间距离缓解假负样本，但其实例关系在训练前固定。NNCLR、PCL 和 SwAV 分别从近邻、原型与聚类分配获得语义正样本，说明固定实例判别目标并不充分。假负样本检测与去偏方法进一步指出，随机负样本可能来自同一语义类别，需要动态识别或概率校正。上述方法主要让正样本来源更丰富，但没有解决企业用户关系中的稳定先验与表示反馈之间的冲突。

内部威胁检测研究从规则、统计和行为画像发展到序列模型、图模型与实时活动级检测。LAN 通过活动级图学习同时建模时间依赖和跨序列关系；近期工作进一步结合异构图、知识提示或多视图对比。与这些方法不同，AdaGraph 不构造新的内部威胁检测器，而是在 TS2Vec 的训练目标中用画像先验锚定用户软正关系，并通过有限表示反馈校正假负样本。该方法的关键是信任域约束下的软图更新，以及异常用户不能被无约束地吸收到正常表示核心。
