## 3. 当前能得出的结论

- 三个软权重控制确实改变了训练器内部的目标；
- `rownorm` 将 active pair mass 从约 174 压缩到约 7.65，尺度通道影响巨大；
- `uniform` 和 `permuq` 保持相同总质量，loss 曲线与 raw `A1-Cov` 近乎一致，
  与三通道审计中 q 接近均匀的结果一致；
- `A0-A3batch` 已匹配到同一 `B_stage`，不再存在步数混杂。

## 4. 不能得出的结论

- 不能从训练 loss 判断检测性能；
- 不能从 `uniform≈Cov` 直接断言关系通道无用，必须做 encode 和固定预算评价；
- 不能把 `rownorm` 的低 loss 解释为更好；
- 不能把这些结果当作 10-seed 确认性证据。

下一步：

1. 从这 12 个 checkpoint 做 encode；
2. 在 r4.2 validation/test 计算 PR-AUC、ROC-AUC 和 K=10；
3. 按预注册数值阈值报告机制效应；
4. 只有 pilot 有方向性信号后，才扩展 10 seed。

## 6. Gate B 结论

当前两 seed pilot 的结论：

- **关系通道：未通过。** `A1-Cov` 对 uniform 的 PR 差值约 `-2.5e-5`，
  对 permuq 约 `-1.3e-5`，远低于预注册 `0.0005`；K10 也未达到预注册门槛。
- **尺度通道：有强信号。** rownorm 明显降低 PR/ROC/K10，说明原始未归一化
  scale 是结果的重要混杂。
- **批次/覆盖路径：有信号。** A1-Cov 相对 A0-A3batch 在两个 test 终点均值
  上均为正，但目前只有 2 个 seed，不能作确认性结论。
- **A1-Cov 相对 A0-matched：脆弱。** PR 均值正向，但 K10 均值仅 `+0.0071`，
  未达到 `max(0.02,1/70)` 的预注册幅度。

因此当前不应启动 10-seed A3/A4 主矩阵。下一步是：

1. 复算两 seed 的用户/事件簇 bootstrap；
2. 检查 A0-A3batch 与 A1-Cov 的差异是否由共同批次覆盖和训练步数造成；
3. 若要继续，只先扩大 A1-Cov/rownorm/uniform/permuq 的 seed 数；
4. 不在关系通道未通过的情况下把它写成主创新。
