# AdaGraph-SoftCLT 预注册表

日期：2026-11-18。

本文件在正式主实验启动前冻结。任何新增主比较必须注明为探索性分析。

## 1. 研究假设

- H1：画像先验锚定的信任域图比固定 47 维画像图更能降低假负样本偏差。
- H2：画像锚、EMA 教师和 KL 信任域分别对稳定性或预测性能有独立作用。
- H3：AdaGraph 的收益不能由更长训练、重复初始化或图稀疏加权解释。
- H4：训练端图校正与打分端欧氏库存在可检验的互补关系。
- H5：AdaGraph 在固定预算、low-and-slow 和原始行为通道扰动下保持运营可用性。

## 2. 训练变体

| 编号 | 定义 | 主要作用 |
| --- | --- | --- |
| A0 | TS2Vec 硬实例负样本 | 原始编码器参照 |
| A1 | 固定 47 维画像软权重，单阶段训练 | R0 主基线 |
| A1+ | 固定画像图，连续训练到指定对照预算 | 等算力对照 |
| A2 | 纯表示图，无画像锚和信任域 | 已有近邻图式路线 |
| A3 | 画像锚 + EMA + 信任域的一次更新 | AdaGraph 单轮核心 |
| A4 | AdaGraph 最多两轮更新 | 主候选方法 |
| A3-noAnchor | EMA + 信任域，无画像锚 | 检验画像锚 |
| A3-noEMA | 画像锚 + 当前表示 + 信任域 | 检验 EMA 教师 |
| A3-noTrust | 画像锚 + EMA，无 KL 信任域 | 检验信任域 |
| A3-hard | 信任域图直接筛选硬近邻 | 检验软权重形式 |
| A5a | 度保持随机图 | 排除稀疏加权 |
| A5b | 打乱用户画像映射，保持图结构 | 检验关系信息本身 |
| A6 | 仅画像中位数维度 | 画像构造消融，放附录 |
| A7 | NNCLR 式近邻正样本 | 近邻对比基线 |
| A8a | Incremental False Negative Detection 适配 | 假负检测基线 |
| A8b | False Negative Cancellation 适配 | 假负抵消基线 |
| A9 | 固定画像图，按 A4 相同轮数重新训练但图不更新 | 排除重复训练与重启收益 |

### 训练预算口径

- 以总优化步数而不是 epoch 名称作为预算单位。
- A1 的基础预算记为 `B`。
- A3 为 `2B`，A1+ 在 H1 比较中使用连续 `2B`。
- A4 为 `3B`，A1+ 在 H2 比较中使用连续 `3B`。
- A9 使用三段 `1B` 的重启训练，总步数 `3B`，图始终固定。
- A7、A8a、A8b 与对应主比较变体使用相同搜索空间、最大试验次数和总步数。

## 3. 主终点与从属终点

共同主终点：

- PR-AUC；
- `K=10` 固定预算事件召回。

机制终点：

- Top-10 邻域一致率；
- 有效秩；
- 图与 LDAP 部门/角色参照的一致性；
- 图边变化率与 KL 漂移。

运营终点：

- 首次命中延迟；
- 每日审查条数；
- 每个真实事件的审查条数。

主终点必须在 r4.2 和 r5.2 上同时评估。r6.2 只作压力审计，不进入显著性推断。

## 4. 确认性比较家族

确认性比较限定为：

1. A4 vs A1；
2. A4 vs A1+（`3B`）；
3. A4 vs A7；
4. A4 vs A8b；
5. A4 vs A9。

每个变体使用两个共同主终点。Holm 校正覆盖 `5 个比较 × 2 个主终点 = 10 个检验`。

以下比较报告效应量与置信区间，标记为机制分析，不纳入主要功效声明：

- A3 vs A3-noAnchor；
- A3 vs A3-noEMA；
- A3 vs A3-noTrust；
- A3 vs A3-hard；
- A3/A4 vs A5a/A5b。

## 5. 成功与失败规则

方法被认定为通过 Gate 1，需要同时满足：

- 两个数据集上，两个共同主终点平均配对差值均大于 0；
- 每个数据集、每个主终点至少 4/5 种子方向一致；
- A4 在确认性比较家族经 Holm 校正后至少有一个主终点显著；
- 次要机制指标没有系统退化；
- A4 相对 A1+、A9、A7、A8b 至少在一个共同主终点上保留正向效应。

若 r4.2 或 r5.2 任一共同主终点平均方向为负，停止 B 类主方法声明。

## 6. Bootstrap

- 主分析单位：用户。对用户进行有放回重采样，并保留该用户全部日期和事件。
- 敏感性分析：事件级 bootstrap。
- 重复次数：10,000。
- PR-AUC 与事件召回应分别计算配对差值的 95% 百分位置信区间。
- 不把用户日作为独立单位，避免低估稀疏行为数据的相关性。

## 7. LDAP 真实 peer 参照

CERT LDAP 中的部门、角色和组织字段只用于评价，不进入训练、图更新或超参数选择。

- 主参照：同部门且同角色；
- 次参照：同部门；
- 指标：Top-10 邻居与参照关系的一致率；
- 对照：固定画像图、A2、A3、A5a、A5b。

LDAP 文件被排除在训练输入之外，只由独立评价脚本读取。

## 8. 批次与排除

### 第一批 pilot

r4.2，1–2 个种子：A1、A1+、A3、A5a、A5b、A7。

### 第二批

Gate 1 pilot 有信号后，5 种子并扩展到 r5.2：A2、A4、A8a、A8b、A9 和 A3 消融。

### 第三批

Gate 1 通过后：深度基线、S 系列交叉、统计检验、安全实验。

排除规则：

- r6.2 不进入显著性检验；
- CERT r1 在完成标签与处理口径审计前不使用；
- SMD 只进入 S 系列和检测基线；
- PSM/SMAP/MSL 不用于 AdaGraph 用户图结论；
- 不含标签的失败运行和 OOM 记录保留，不进入性能主表；
- 不用测试期事件决定 epoch、α、τ、β、top-m 或早停。

## 9. 标签隔离

训练期早停只允许使用：

- 训练损失；
- 训练期内部验证损失；
- 有效秩；
- 各向同性；
- 图边变化率和 KL 漂移。

“异常用户进入正常核心比例”需要测试标签，只能作事后诊断，不能触发早停。
