## 三、问题定义

TS2Vec 在训练端和打分端各存在一个信息损失点。

### 3.1 训练端：硬负样本造成正常类碰撞

原始实例对比把所有其他实例都当作负样本。用户行为中大量正常用户、正常日期具有相似分布，直接推开会产生假负样本。

SoftCLT 将硬 0/1 权重替换为数据空间软权重：

\[
w_I(u,v)=
\frac{2\alpha}
{1+\exp(\tau_I D_{uv})}
(1-\alpha)\mathbf 1[u=v]
\]

距离越近，正关系权重越高。

### 3.2 打分端：余弦与中心距离丢失径向信息

TS2Vec 原始评分使用遮罩表征差异。表征库余弦距离只比较方向，不比较径向幅度；欧氏距离同时保留方向和尺度。

本项目首先把“余弦→欧氏”作为诊断，不把加权项当作既定成功。

## 五、47 维用户画像距离

每个用户只在训练期活跃日上构造画像：

\[
\phi_u=
\left[
\operatorname{median}_{k}(x_{u,k}),
q_{90,k}(x_{u,k}),
\operatorname{active\_fraction}_u
\right]_{k=1}^{23}
\]

包括 20 个计数特征和 3 个时间特征：

- 首次登录分钟；
- 最后登出分钟；
- 活跃跨度。

因此维数为：

```text
23 median + 23 q90 + 1 active fraction = 47
```

画像逐维跨用户标准化后计算欧氏距离：

\[
D_{uv}=\|\tilde\phi_u-\tilde\phi_v\|_2
\]

带宽：

\[
\tau_I=
\frac1{\operatorname{median}_{u<v}(D_{uv})}
\]

固定 `alpha=0.5`。

### 5.1 为什么不用 DTW

CERT 是高维稀疏日计数，存在非活跃日和缺失；DTW 容易混入对齐伪路径，且数千用户两两 DTW 成本高。

画像距离保留典型强度、尾部强度、时间习惯和活跃持续性，但忽略完整顺序与状态转移，因此仅是 CERT 的适配假设。

### 5.2 构造效度

把训练期切成前后两段，分别重建画像和距离：

| 数据 | 前后半段距离秩相关 | 41 维 Top-10 重合率 | 47 维 Top-10 重合率 |
| --- | ---: | ---: | ---: |
| r4.2 | 0.978 | 0.640 | **0.700** |
| r5.2 | 0.965 | 0.534 | **0.625** |
| r6.2 | 0.958 | 0.317 | **0.422** |

47 维画像在三个数据上均提高了正常邻域的时间稳定性。该实验不使用异常标签。

### 6.3 几何机制：为什么 instance-soft 有效，temporal-soft 没有独立收益

对比学习可以看作在表示空间中构造正样本图。instance-soft 的权重由用户画像距离决定：

\[
w^I_{u,v}=\frac{2\alpha}{1+\exp(\tau_I d^X_{u,v})}
\]

它新增的是**内容相关的跨用户弱正边**。标准 instance 对比把不同用户全部推向负侧，会让行为相似但 ID 不同的正常用户成为假负例，从而切碎正常流形。Soft instance 用画像距离放行这些相似用户，因此应同时改善数据邻域保持和有效秩。

temporal-soft 的权重只由时间索引差决定：

\[
w^T_{t,s}=\frac{2}{1+\exp(\tau_T\,2^d|t-s|)}
\]

它是用户内的时间低通平滑先验，不包含跨用户语义。CERT 日行为受工作日、岗位、休假和稀疏活动影响，相邻日期不等于语义相同；点异常本身还常表现为局部高频偏离。把相邻日期强行拉近，可能同时压低异常方向。

必须拆开比较：

| 对比 | 变化 | 结果解释 |
| --- | --- | --- |
| T1 → T2 | hard temporal → soft temporal，且都没有 instance 项 | soft temporal 略优于 hard temporal，但仍远低于有 instance 项的模型 |
| T3 → T4 | instance-soft 固定，加入 temporal-soft | PR/ROC/kNN/有效秩均轻微下降 |

三 seed 几何摘要：

| 模型 | instance 项 | temporal 项 | kNN overlap | 局部距离 Spearman | 有效秩 | 平均范数 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| T0 | hard | hard | 0.3902 | 0.4401 | 8.884 | 3.464 |
| T1 | 无 | hard | 0.2601 | 0.3974 | 5.110 | 3.271 |
| T2 | 无 | soft | 0.2149 | 0.4498 | 7.669 | 1.972 |
| T3 | soft | hard | **0.4977** | **0.5034** | **14.696** | 1.380 |
| T4 | soft | soft | 0.4952 | 0.4933 | 14.375 | 1.357 |

进一步计算图的 normalized Dirichlet energy 和高频残差 AUC：

| 模型 | instance Dirichlet | temporal Dirichlet | instance residual ROC | temporal residual ROC |
| --- | ---: | ---: | ---: | ---: |
| T0 | 0.2937 | 0.2829 | 0.7950 | 0.6071 |
| T1 | 0.0936 | 0.4555 | 0.7756 | 0.6325 |
| T2 | 0.1265 | 0.3457 | 0.7606 | 0.6966 |
| T3 | 0.3456 | 0.2452 | **0.8407** | 0.7651 |
| T4 | 0.3352 | **0.2395** | 0.8398 | **0.7717** |

这组结果修正了纯“低通滤波”的解释：

- `T1→T2`：temporal Dirichlet 下降 `0.1098`，temporal residual ROC 上升 `0.0642`，说明 temporal-soft 确实在平滑时间图，并改善时间残差的局部可分性；
- `T3→T4`：temporal Dirichlet 再下降 `0.00565`，temporal residual ROC 上升 `0.00660`，但 instance residual、kNN、有效秩和最终 PR/ROC 没有同步改善；
- `T3` 相对 `T0` 的 instance Dirichlet 反而上升 `0.0519`，但 instance/temporal residual ROC 和 kNN 明显提高，说明 instance-soft 不是简单“压平图”，而是重校准了内容相关的正样本重心。

因此最准确的结论不是“temporal-soft 算法本身无效”，而是：

> 在 `lambda=0` 的 temporal-only 方案里，soft temporal 无法替代跨用户 instance 对比；在 `lambda=0.5` 的完整方案里，它改善了时间高频残差的局部可分性，但没有在 instance-soft 之上形成稳定的端到端增益。instance-soft 的机制更接近“语义图重校准”，不能简化成低通平滑。

完整推导见 `docs/current/SoftCLT_几何机制与成立条件_20261117.md`。

## 十三、最终研究结论

表征信息保全不是简单的两个模块相加，而是围绕同一个信息损失机制：

- 训练端减少正常类碰撞，保全正常邻域关系；
- 打分端减少径向幅度丢失，保全表征强度。

机制实验支持正常邻域结构得到改善；r4.2/r5.2 支持联合模型在点级排序和预算事件召回上的方向性收益；SMD 的同窗口对照提供轻微外部增量；r6.2 的五事件审计暴露外部事件级有效性仍不足。

与经典 iForest 基线相比，T4+PAI-A1 在 r4.2 test 的 PR-AUC、ROC-AUC、K=5、K=10 和 K=20 上均更高；同时 iForest 已接近 Native TS2Vec，说明单日表格离群点本身包含异常信息，双端优化的优势并非只来自“使用时序模型”这一形式。

因此当前最稳妥的定位是：

> **一项针对 TS2Vec 的方法组合、CERT 适配与严格验证工作，核心创新是统一的表征信息保全原则、47 维画像距离适配和多协议外部审计，而不是发明新的基础神经网络。**
