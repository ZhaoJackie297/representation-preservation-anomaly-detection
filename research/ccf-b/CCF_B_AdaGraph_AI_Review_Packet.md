## 研究问题

TS2Vec 的硬实例对比会把行为相近的正常用户当作负样本。固定 47 维画像距离只能提供静态规则，无法随表示学习调整；纯表示近邻图又会自我强化。

本文研究的问题是：

> 能否用稳定画像先验约束表示反馈，在有限信任域内学习用户软关系图，从而降低假负样本偏差，同时避免异常用户被吸收到正常表示核心？

## 方法：AdaGraph-SoftCLT

### 1. 画像先验

用训练期 47 维鲁棒画像构造用户关系先验 `P`。画像只使用行为和时间特征，不使用 LDAP 部门、角色或团队字段。

### 2. EMA 表示距离

用第一阶段模型的 EMA 教师表示计算用户距离，并对 EMA 表示停止梯度。距离按行中位数归一化：

```text
d_tilde(u,v) = d_EMA(u,v) / median_{v != u} d_EMA(u,v)
```

若行中位数过小，使用预先定义的数值下限，避免温度失效。

### 3. 支撑集

对每个用户 `u`，按以下分数选择 top-m 邻居：

```text
score(u,v) = P(u,v) * exp(-d_tilde(u,v) / tau)
```

在选出的支撑集 `S_m(u)` 上，将画像先验 `P` 重新归一化为 `P_m`。所有 KL 计算都在该支撑集上完成。

### 4. 信任域更新

对每个用户行求解：

```text
min_{W in simplex} <W, d_tilde> - tau * H(W)
s.t. KL(W || P_m) <= epsilon
```

在支撑集上得到：

```text
W_beta(u,v) ∝ P_m(u,v)^beta *
               exp(-(1 - beta) * d_tilde(u,v) / tau)
beta = lambda / (tau + lambda), 0 <= beta < 1
```

KL(W || P_m) 随 beta 单调下降。二分搜索 beta，使其满足 KL 上界；如果 beta=0 已满足约束，则直接取 beta=0。

- `beta=0` 表示纯表示图；
- `beta` 增大表示更多保留画像先验；
- `beta` 接近 1 时回到画像图。

行熵已经由目标中的 `tau * H(W)` 控制，不再额外增加行熵约束。行熵只作为监控指标。

### 5. 两轮更新

- A1：固定画像图，训练 `B` 个优化步。
- A3：画像图训练 `B` 步，更新一次图，再从当前权重继续训练 `B` 步。
- A4：在 A3 基础上再更新一次图，从当前权重继续训练 `B` 步。
- A1+：固定画像图连续训练到与 A3 或 A4 相同的总步数。
- A9：固定画像图，按与 A4 相同的三段预算继续训练，但图不更新。

所有阶段重置优化器状态，并采用同一种按阶段缩放的 warmup-cosine 调度。A1+ 使用与总训练预算对应的单一 warmup-cosine 调度。

## 与已有工作的区别

- SoftCLT：实例距离固定，来自原始数据空间。
- NNCLR：用当前表示支持集最近邻构造正样本，没有画像锚。
- PCL、SwAV：依赖原型或聚类分配。
- Incremental False Negative Detection、False Negative Cancellation：动态检测或抵消假负样本，没有稳定用户先验和信任域约束。
- TGMC 等图对比内部威胁方法：构造异构图和专用图编码器；AdaGraph 只校正 TS2Vec 训练中的实例软权重。

AdaGraph 的新颖性必须限定为：

> 画像锚定、EMA 表示反馈和 KL 信任域约束下的实例软权重图学习。

不能宣称首次将图或对比学习用于内部威胁检测。

## 理论目标

当前 Proposition 1 只是标准加权 InfoNCE 梯度。B 类版本至少需要：

1. 将 InfoNCE 梯度分解为真负样本、假负样本和正样本；
2. 给出假负样本偏差与错误软权重之间的上界；
3. 给出 KL 信任域下表示图相对画像图的漂移界；
4. 给出 AdaGraph 优于固定画像图和纯表示图的条件。

## 2. 研究假设

- H1a：画像先验锚定的软图相对纯表示图降低假负样本偏差。
- H1b：AdaGraph 相对固定画像软权重取得端到端收益。
- H2a：在其他组件固定时，画像锚的边际贡献为正。
- H2b：在其他组件固定时，EMA 教师的边际贡献为正。
- H2c：画像关系信息不是随机稀疏加权带来的假收益。
- H3：AdaGraph 的收益不能由更长训练或重复优化器重启解释。
- H4：训练端 AdaGraph 与打分端欧氏库的交互为正。H4 为探索性假设。

不再声称画像锚和 KL 信任域是两个可以独立开关、独立识别的组件。二者由同一个 `beta` 控制，只能研究锚/信任强度的剂量响应。

### 训练预算

- 预算单位：优化器步数，不是 epoch 数。
- A1 和 A8 等方法的基础预算记为 `B`。
- A3 为 `2B`；A4 为 `3B`。
- A1+ 使用连续 `2B` 或 `3B`，并按总预算重新设置 warmup-cosine 调度。
- A4 后两段和 A9 三段均从上一段权重继续，每段重置优化器状态。
- 逐种子配对要求同一 seed 下的数据顺序、图初始化、模型初始化和 batch 顺序相同。

## 4. 无标签超参数选择

所有训练方法和基线使用同一选择协议：

1. 在训练期内部再切出一段完全早于首个真实恶意事件的时间作为 inner-validation。
2. 从 inner-validation 的正常行为注入固定合成异常：幅度尖峰、多通道突发、低幅缓慢漂移。
3. 每个机制固定 3 个强度，仅使用合成标签评价。
4. 选择分数：

```text
J = mean synthetic PR-AUC across 3 mechanisms x 3 strengths
```

5. 为避免耦合打分端搜索，`J` 固定使用 S2 欧氏表征库。
6. 每个方法族最多 20 次训练：12 个候选各跑 1 个调参 seed；前 4 名各补 2 个调参 seed。
7. 若 `J` 相同，依次比较 RankMe 有效秩和较低图漂移。
8. 调参完成后，在完整训练期上重训 10 个正式 seed。
9. A7、A8a、A8b 和深度基线使用同样的 inner-validation、合成异常和 20 次上限。

真实 validation/test 标签不得参与模型选择。合成异常生成器、强度和随机种子预注册后固定。

## 5. 主终点与推断

共同主终点：

- PR-AUC；
- `K=10` 固定预算事件召回。

预注册 10 个种子：`20261116` 至 `20261125`。

主推断：

1. 对每个 seed 计算配对差值；
2. 先在 10 个 seed 上求平均；
3. 条件于已训练模型，对用户/事件簇做配对 bootstrap；
4. bootstrap 重复 10,000 次；
5. 用户日是协变量，不作为独立重采样单位。

显著性与区间：

- 单侧 `alpha=0.025`，对应双侧 95% 区间；
- 优效性 p 值：`(1 + #{Delta* <= 0}) / (B + 1)`；
- 非劣效性 p 值：`(1 + #{Delta* <= delta_margin}) / (B + 1)`；
- 确认性 p 值进入 Holm 校正；
- 置信区间只作为效应量和不确定性展示，不替代预注册 p 值规则。

### K=10 固定排名 bootstrap

采用固定排名方案，不在 bootstrap 中重新计算每日 Top-K：

1. 原始用户池上固定每个模型的每日 Top-K 名单；
2. 按用户聚类重采样，保留用户的全部日期、告警命中和事件；
3. 多用户事件作为同一事件簇整体重采样，避免拆散事件；
4. 在固定名单上计算重采样后的召回；
5. 不增加候选池、不重新排序、不产生重复用户的新 Top-K。

PR-AUC 的用户聚类 bootstrap 使用用户多重权重计算；事件级 bootstrap 只作敏感性分析。

## 6. 确认性比较

确认性数据集只有通过审计的 CERT r1。

确认性比较：

1. A4 vs A1；
2. A4 vs A1+（`3B`）；
3. A4 vs A7；
4. A4 vs A8b；
5. A4 vs A9。

每个比较有两个共同主终点。Holm 在 r1 上覆盖 `5 x 2 = 10` 个检验。

- A4 vs A1 是端到端收益，不作组件归因。
- A4 vs A1+ 和 A4 vs A9 是算力归因。
- A4 vs A7/A8b 是已有方法对比。

Gate 1 的算力主张采用交并规则：A4 必须相对 A1+ 和 A9 在**两个共同主终点**上均满足优效性。

A7/A8b 的比较采用“至少一个主终点优效，且两个主终点均非劣”：

- PR-AUC 非劣界：参考方法的 `-5%` 相对值；
- K=10 召回非劣界：参考方法的 `-5%` 相对值。

A8a 是显式删除假负样本的抑制式方法，与 A8b 的软抵消机制不同，因此保留为探索性基线；其全部结果必须报告，但不进入主确认性家族。

正式开跑前必须读取 R0 结果完成最小可检测效应估计：

- 使用 10 个种子的观测方差和用户聚类 bootstrap 宽度；
- 估计 PR-AUC 与 K=10 召回在 `alpha=0.025`、Holm 和 80% 功效下的最小可检测效应；
- 若实际可检测效应大于业务上有意义的差异，则调整样本设计或终止 B 类主张。

## 7. 机制分析

机制比较单独构成预注册小家族，在 r1 上使用 `alpha=0.025` 和 Holm：

1. A3 vs A3-noAnchor；
2. A3 vs A3-noEMA。

每个比较使用两个共同主终点，共 4 个检验。A3-product、A3-hard、β 剂量响应、A2 等其他对照标记为机制或探索性分析。

画像/信任强度使用剂量响应：

```text
epsilon = {0, 0.001, 0.01, 0.05, 0.1, 0.2, 0.5, infinity}
```

- `epsilon=0` 对应纯画像图；
- `epsilon=infinity` 对应纯表示图；
- 中间网格对应不同信任域强度；
- 逐用户记录实际 `beta`、有效温度和 KL。

EMA 与锚使用 2×2 单元：A4、A3-noAnchor、A3-noEMA、A2。

## 8. 假负偏差与关系质量

### FN 代理量

使用 CERT LDAP 的部门/角色关系作为评价标签，不进入训练：

```text
PeerMass(u) =
  sum_{v: same department and role} W(u,v)
```

报告：

- `PeerMass@top-m` 的均值；
- Top-10 邻居的组织结构一致率；
- 同部门、同部门且同角色的加权召回。

LDAP 只用于评价和半合成验证，不进入 `P`、`d_EMA`、图更新或调参。

### 邻域一致率

定义原始 47 维画像邻域与学习后用户表示邻域的 Top-10 Jaccard：

```text
NCA@10 =
  mean_u |N10_raw(u) intersect N10_repr(u)| /
         |N10_raw(u) union N10_repr(u)|
```

非劣比较对象为同一预算下的 A1+。95% CI 下界不得低于 `-0.02`。

### 有效秩

使用 RankMe 有效秩相对 A1+ 的比值：

```text
ER_ratio = ER_method / ER_A1plus
```

非劣界为 0.90，即 95% CI 下界不得低于相对有效秩 0.90。

### 半合成验证

构造带已知 peer class 的用户行为数据：

1. 正常行为生成器按部门/角色设置潜在类；
2. 同类用户共享强度分布，但保留个体噪声；
3. 异常按幅度、上下文和集体机制注入；
4. 比较候选图与真实潜在 peer 关系的 AUC、PeerMass 和检测性能。

半合成数据只用于验证 FN 代理量，不替代真实 CERT 结论。

### 外部基线适配

所有表示学习基线统一到用户级实例：

- 每个用户训练期序列是一个 instance；
- 用户表示由训练期活跃日表示归一化平均得到；
- NNCLR 的支持集使用同一 EMA 用户表示库，`k` 与 AdaGraph 的 top-m 网格一致；
- Incremental False Negative Detection 和 False Negative Cancellation 都在相同用户级负样本池上运行；
- 基线若必须偏离原论文，需在附录记录输入、正负样本单位和训练步数的改动。

## 9. Gate 1

以下条件全部满足才算通过：

- r1 标签和账户映射审计通过；
- A4 相对 A1+ 和 A9 在两个共同主终点上均优效；
- A4 相对 A7/A8b 至少一个主终点优效，且两个终点均非劣；
- A4 相对 A1 有端到端正向收益；
- A4 相对 A5a/A5b 至少一个共同主终点方向为正，且至少 8/10 seed 为正；
- NCA@10 非劣界满足；
- ER_ratio 非劣界满足；
- A3 相对 noAnchor/noEMA 的机制家族至少一个主终点正向；
- 不存在有效秩持续下降、表示各向同性异常上升或异常用户进入正常核心的事后警示。

任一关键条件失败，不把 AdaGraph 写成 B 类新方法。

## 10. 数据结构与实现规格

### 画像先验 `P`

- 使用现有 47 维训练期鲁棒画像；
- 排除部门、角色、团队和 LDAP 派生字段；
- 每维用训练用户的中位数和 IQR 标准化；
- `D_profile` 为欧氏距离；
- 带宽 `h=median(D_profile)`；
- `P_raw(u,v)=max(exp(-D_profile(u,v)^2/(2h^2)), 1e-12)`，`u!=v`；
- 对角置 0，然后逐行归一化；
- 支撑集上的 `P_m` 再从上述正概率重新归一化，保证 KL 有定义。

### EMA 用户表示

- 每阶段开始时 EMA 教师权重直接复制学生权重，不初始化为零；
- 只使用训练期活跃日；
- 先对每日时间戳表示做 L2 归一化，再对活跃日均值归一化，得到用户表示；
- `d_EMA(u,v)=1-cosine(z_u,z_v)`；
- 行中位数归一化；
- 行中位数下限 `1e-6`；
- EMA decay 搜索只使用 `{0.99, 0.995}`，不使用在 B 步内几乎不更新的 0.999。

### 支撑集与 KL

- `score(u,v)=P(u,v)*exp(-d_tilde(u,v)/tau)`；
- 支撑集 `S_m(u)` 按 score 取 top-m；
- 在支撑集上重归一化 `P_m`；
- KL 只在 `S_m(u)` 上计算；
- beta 二分容差 `1e-6`，最大 64 次；
- 若无可行 beta，回退 `beta=1` 并记录失败。

### W 到 SoftCLT

- 每行 `W_beta` 在支撑集上归一化为概率分布；
- SoftCLT 自权重保持 1；
- 对 `i!=j`，正关系权重直接取 `W_beta(i,j)`；
- 不按 m 再乘缩放系数，因此邻居总权重固定为 1，与支撑集大小无关；
- 未进入支撑集的用户对作为普通负样本。

### EMA 更新

- EMA 在阶段内逐步更新，并记录教师-学生余弦距离；
- 要求 `B >= 3/(1-decay)`；否则该 decay 标记为低有效更新并不得用于正式模型。

## 11. 参数搜索范围

- EMA decay：`{0.99, 0.995}`；
- tau：`{0.05, 0.1, 0.2, 0.5, 1.0}`；
- epsilon：`{0, 0.001, 0.01, 0.05, 0.1, 0.2, 0.5, infinity}`；
- top-m：`{10, 20, 50}`；
- A7 的近邻数 `k` 使用同一 `{10,20,50}` 网格；
- 学习率和 weight decay 使用相同搜索空间；
- 每个方法族最多 20 次调参训练。

当 `epsilon=0` 时直接取纯画像图；当 `epsilon=infinity` 时直接取纯表示图，并记录 beta 实际值。

## 12. 算力口径

R0 单次 `B=10 epochs` 的实测耗时大约为：

- r4.2：`149–194 s`；
- r5.2：`168–411 s`；
- r6.2：`145–261 s`。

A4 的 `3B` 预计约 `8–20 min` 一次，具体取决于数据和机器状态。按单张 RTX 5060、24 小时运行，计划将调参限制在 r4.2 的内部验证，并把深度基线限制为 r5.2/SMD 的最低必要矩阵。正式开跑前需用 run registry 记录实际 GPU 小时；若预计超过 8 周预算，先削减探索性变体，不削减主比较。

## 13. 批次

### Pilot

r4.2，1–2 个 seed：A1、A1-sparse、A1+、A3、A5a、A5b、A7。
Pilot 只判断效应方向，不作确认性推断；一旦使用 r4.2 测试期方向决定是否进入第二批，r4.2 即失去最终盲测地位。

### 第二批

Pilot 有信号后：r4.2 + r5.2，10 seed，运行 A2、A4、A8a、A8b、A9 和机制消融。

### 确认与安全

r1 审计通过后运行确认性矩阵。深度基线、S×A 和完整安全实验在 Gate 1 通过后启动。

A7、A8a、A8b 优先使用官方代码适配，并记录相对原论文的必要改动。三者与 AdaGraph 使用相同最大调参试验次数；若有官方默认配置，先按官方配置运行一次，再做同预算调参。

## A0. 无标签调参

每个方法族最多 20 次训练：12 个候选各跑 1 个调参 seed，前 4 名各补 2 个调参 seed。

- 调参只使用 r4.2 训练期内部的合成异常验证；
- 合成异常包含幅度尖峰、多通道突发和低幅缓慢漂移，固定 3 个强度；
- 选择分数为固定 S2 欧氏打分下的平均 synthetic PR-AUC；
- 同分时依次按 RankMe 有效秩和较低图漂移决定；
- 选择后固定超参数，在完整训练期上重训 10 个正式 seed；
- A7、A8a、A8b 和深度基线使用相同选择和试验预算。
- A7 的最近邻数量 `k` 使用与 AdaGraph 相同的 `{10,20,50}` 网格。

真实 validation/test 标签不参与模型选择。

每轮图更新必须记录：

- 边变化率；
- 与固定画像图的重合率；
- 行熵；
- KL 漂移；
- 有效秩与表示各向同性；
- 异常用户进入高相似正常核心的比例，仅用于测试后的事后诊断。

训练期早停只能使用训练损失、训练期内部验证、有效秩、各向同性、边变化率和 KL 漂移。需要测试标签的指标不得参与训练或早停。

## A-Ref. 组织结构参照评价

CERT LDAP 的部门、角色和组织字段只用于评价，不进入训练、图更新或调参。

- 主参照：同部门且同角色；
- 次参照：同部门；
- 指标：Top-10 邻居与参照关系的一致率；
- 对照：A1、A2、A3、A4、A5a、A5b、A7。

47 维画像的输入特征必须排除部门、角色、团队和任何 LDAP 派生字段，避免循环论证。

假负偏差主代理量为：

```text
PeerMass(u) = sum_{v: same department and role} W(u,v)
```

同时报告 Top-10 组织结构一致率、同部门召回和同部门且同角色召回。该指标只用于评价和半合成验证，不进入图学习。

```text
NCA@10 =
  mean_u |N10_raw(u) intersect N10_repr(u)| /
         |N10_raw(u) union N10_repr(u)|
```

比较对象是同一预算下的 A1+。有效秩使用 `ER_ratio=ER_method/ER_A1plus`，非劣界为 0.90。

## B. 打分端实验

| 代号 | 表示库距离 | 用途 |
| --- | --- | --- |
| S0 | mask L1 | Native TS2Vec 官方分数 |
| S1 | 余弦表征库 | 方向距离基线 |
| S2 | 欧氏表征库 | 幅度保留主方法 |
| S3 | 欧氏库 + magG | 单点幅度消融 |
| S4 | 欧氏库 + T2 | 持续漂移消融 |
| S5 | 完整 PAI | 探索性组合 |

Gate 1 前只跑主交叉 `A1/A4 × S1/S2`，即四个单元：

| 训练端 | 打分端 |
| --- | --- |
| A1 | S1 余弦 |
| A1 | S2 欧氏 |
| A4 | S1 余弦 |
| A4 | S2 欧氏 |

RQ3 的主交互对比定义为：

```text
Delta_interaction =
  (M_A4_S2 - M_A4_S1) -
  (M_A1_S2 - M_A1_S1)
```

`Delta_interaction > 0` 表示欧氏打分在 AdaGraph 上的增量大于在固定画像图上的增量。H4 明确标为探索性，不进入 Gate 1。Gate 1 通过后，再做 A1–A4 与 S0–S5 的完整交叉。

| PSM / SMAP / MSL | 打分端外部验证与规避分析 | 尚未接入；不宣称 AdaGraph 用户图适用 |

优先新增一个连续时序集用于打分端外部验证。AdaGraph 的用户图结论只在 CERT 用户行为数据上成立；若要迁移到连续时序数据，需要重新定义节点和边，不能直接套用用户关系图。

## E. 统计与复现

- 种子：直接预注册 `10` 个；
- 汇总：均值、标准差、配对差值和 95% 置信区间；
- 确认性数据集：CERT r1；
- 确认性比较家族：A4 vs A1、A4 vs A1+、A4 vs A7、A4 vs A8b、A4 vs A9；
- 多重比较：Holm 覆盖 r1 上 5 个比较 × 2 个共同主终点，共 10 个检验；
- 单侧 `alpha=0.025`，对应双侧 95% 区间；
- 优效 p 值：`(1 + #{Delta* <= 0})/(B+1)`；
- 非劣 p 值：`(1 + #{Delta* <= delta_margin})/(B+1)`；
- 主推断：先对 10 个种子求配对平均，再按用户/事件簇做配对 bootstrap；
- Bootstrap 敏感性分析：事件级重采样；
- Bootstrap 重复次数：至少 10,000 次；
- 结果冻结：每次训练写入不可覆盖的 `run_id`；
- 随机性：Python、NumPy、PyTorch、DataLoader 和图初始化均固定；
- 失败实验：保留在报告中，不按结果删实验。

### K=10 固定排名 bootstrap

- 在原始用户池上为每个模型固定每日 Top-K 名单；
- bootstrap 中不重新排名，也不改变候选池；
- 按用户/事件簇重采样，并整体保留该用户的日期、命中和事件；
- 多用户事件作为同一事件簇整体采样；
- 用固定告警名单计算重采样后的召回。

PR-AUC 的用户聚类 bootstrap 使用用户多重权重。事件级 bootstrap 仅用于敏感性分析。

## F. 安全与运营实验

### F1. Low-and-slow

使用相同总攻击量构造两条曲线：

- 单日一次性注入；
- 多日递增 low-and-slow。

比较余弦、欧氏和 T2 在以下指标上的变化：

- 首次命中延迟；
- K 条告警内的事件召回；
- 误报数量和误报持续时间。

### F2. 幅度与方向扰动

主实验只操纵原始行为通道。表示层扰动仅作敏感性分析，因为攻击者直接控制嵌入不符合部署威胁模型。

原始行为层扰动包括：

- 径向幅度缩放；
- 通道替换；
- 时间平移；
- 随机通道缺失。

表示层仅补充：

- 小幅方向旋转；
- 嵌入幅度缩放。

威胁模型必须明确攻击者是否：

- 知道特征定义和评分方向；
- 能修改单个行为通道或多个通道；
- 有每日总扰动预算；
- 能在训练后适应阈值。

规避实验输出“检测率—扰动强度”曲线，而不是只报告一个扰动点。

### F3. 运营成本

统计不同 K 下的：

- 每日审查条数；
- 有效告警率；
- 重复告警冷却节省量；
- 每发现一个真实事件的审查条数。

审查时间采用 `5`、`10`、`20` 分钟/条三档假设，并报告排序结论是否随假设改变。当前阶段没有可靠文献支持具体分钟数，因此论文必须明确标为场景假设，而不是实测运营数据。

### F4. 案例研究

案例选择规则在查看结果前固定：

- 成功案例：在 K=10 命中的事件中取官方事件编号最小者；
- 延迟案例：在 K=10 命中的事件中取首次命中延迟最大者；
- 失败案例：在 K=10 未命中的事件中取官方事件编号最小者。

至少选择这 3 个 CERT 事件，给出：

- 首次进入 Top-K 的日期；
- 命中前的主要行为通道；
- magG、T2、欧氏距离和证据视图；
- 冷启动或持续异常情况；
- 证据报告如何帮助人工复核。

如果事件数量不足，按事件编号顺序向后替补，并记录选择过程。案例正文必须说明漏报、延迟或证据误导的具体原因。

## 停止条件

以下任一情况出现时，暂停 B 组实验并回到方法层修正，不能靠增加论文篇幅掩盖：

- AdaGraph 在 r1 的 A1+ 或 A9 对照上不能同时取得两个主终点优效；
- A4 相对 A7 或 A8b 任一主终点超过 5% 相对非劣界；
- A4 相对 A5a 或 A5b 没有任何方向性优势；
- A3 相对 noAnchor 或 noEMA 的机制家族没有任何主终点正向；
- 小 epsilon 下与 A1-sparse 无差异；
- 10 种子中方向一致性低于 8/10；
- 机制指标改善但端到端指标持续下降；
- 深度基线在同一协议下无法公平运行；
- S4 无法生成可复核证据；
- low-and-slow 下固定预算告警完全失效且没有明确边界分析。

如果 AdaGraph 未通过，但画像稳定性、固定预算和证据审计依然完整，可以把论文转为“自监督异常检测的诊断框架与系统性实证研究”。这种版本可以继续冲 C，不能包装成 B 类新方法。

## 一、直接基础

### TS2Vec

TS2Vec 在增强后的上下文视图上进行层次化实例与时间对比，并学习时间戳级表示。它是本项目的主干编码器。已核实：Yue 等，AAAI 2022，arXiv:2106.10466。

### SoftCLT

SoftCLT 将硬 0/1 对比关系替换为 0 到 1 的软权重。实例项使用数据空间距离，时间项使用时间戳差；在异常检测配置中，原论文默认关闭 instance-soft，主要验证 temporal-soft。已核实：Lee、Park、Lee，ICLR 2024 Spotlight，arXiv:2312.16424。

与本项目的关系：AdaGraph 保留 SoftCLT 的软对比形式，但不固定实例距离。画像距离作为先验，表示反馈只能在信任域内更新关系图。

## 二、近邻、原型与聚类对比

### NNCLR

NNCLR 在表示空间的支持集中检索最近邻，并将最近邻作为额外正样本。已核实：Dwibedi 等，ICCV 2021，DOI:10.1109/ICCV48922.2021.00945。

区别：NNCLR 的正样本完全由当前表示决定；AdaGraph 的边由画像先验约束，EMA 表示只提供有限反馈。NNCLR 式近邻是本项目必须实现的基线。

### PCL

PCL 在 EM 框架下迭代聚类原型和对比表示，通过 ProtoNCE 将样本拉向原型。作者 Li、Zhou、Xiong、Hoi；OpenReview ID `KmykpuSrjcq`，ICLR 2021。

区别：PCL 学习簇原型，AdaGraph 不替换用户原型，而是校正用户对之间的正关系权重。

### SwAV

SwAV 通过交换视图的聚类分配进行自监督学习，并使用多裁剪增强。已核实：Caron 等，NeurIPS 2020，arXiv:2006.09882。

区别：SwAV 的聚类分配是训练目标核心；AdaGraph 的图只进入实例正关系权重，保留 TS2Vec 的层次对比结构。

### MoCo

MoCo 使用队列和动量编码器构造大而一致的负样本字典。已核实：He 等，CVPR 2020，arXiv:1911.05722。

区别：MoCo 关注负样本字典规模与一致性；AdaGraph 关注用户行为语义相似造成的假负样本，不以扩大字典为目标。

## 三、假负样本与去偏

### Incremental False Negative Detection

该方法在训练过程中逐步检测并显式移除以假负样本。已核实：Chen 等，ICLR 2022，arXiv:2106.03719。

区别：该方法主要依赖当前表示空间动态检测；AdaGraph 额外使用稳定画像先验，并限制图漂移。

### False Negative Cancellation

Huynh 等在 WACV 2022 提出 False Negative Cancellation，对潜在同类负样本进行识别和抵消；DOI:10.1109/WACV51458.2022.00106。

注意：文献中的 `False Negative Cancellation` 与 Chen 等的 `Incremental False Negative Detection` 是两项不同工作，引用时不能混写。

### Debiased Contrastive Learning

Chuang 等通过估计同类负样本比例修正 InfoNCE 偏差，并给出下游泛化界。已核实：NeurIPS 2020，arXiv:2007.00224。

区别：Debiased CL 通常估计全局或采样层面的负样本污染；AdaGraph 使用用户级画像先验和表示反馈构造局部软关系。

## 四、表示塌缩与无标签质量控制

### Dimensional Collapse

Jing 等指出，对比学习也可能发生维度塌缩，即表示仅占据低维子空间。已核实：ICLR 2022，arXiv:2110.09348。

AdaGraph 必须逐轮记录有效秩、各向同性和异常用户进入正常核心的比例，不能只观察训练损失。

### RankMe

RankMe 使用表示矩阵的有效秩作为无标签质量指标，并可辅助超参数选择。已核实：Garrido 等，ICML 2023，arXiv:2210.02885。

## 五、内部威胁检测

### CERT 与早期无监督方法

CERT 数据集由 Glasser 和 Lindauer 在 2013 年 IEEE Security and Privacy Workshops 的论文中介绍。Tuor 等在 2017 年 AAAI AICS workshop 使用结构化日志做无监督深度检测。Yuan 与 Wu 在 Computers & Security 2021 综述了内部威胁检测的挑战与机会。

### LAN

LAN 面向活动级实时内部威胁检测，同时学习活动序列内的时间依赖和跨序列关系，并处理审查预算和类别不平衡。已核实：Cai 等，IEEE TIFS 2024，DOI:10.1109/TIFS.2024.3488527。

区别：LAN 构造活动级图并做实时告警；AdaGraph 是日级自监督表示训练中的软正关系校正。

### Ripple2Detect

Ripple2Detect 关注基于语义相似学习的多步内部威胁证据检测。已核实：Liu 等，Computers & Security 2025，DOI:10.1016/j.cose.2025.104387。由于本次未取得摘要，不在正文中扩展其具体算法细节。

### ATHITD

ATHITD 是基于注意力时序异构图神经网络的内部威胁检测方法。已核实：Qi 等，Computers & Security 2025，DOI:10.1016/j.cose.2025.104587。由于本次未取得摘要，只作为近期图关系方法引用。

### Knowledge-Enhanced Prompt Contrastive Learning

Yu 等提出面向多源用户行为图的知识增强自对比框架，使用关系编码的多头注意力、子图采样、提示文本对齐、VAE 过滤和多分类。已核实：Yu 等，IJCNN 2025，DOI:10.1109/IJCNN64981.2025.11229300。

区别：该方法依赖知识提示和行为图编码器；AdaGraph 不生成文本提示，也不改变 TS2Vec 主干。

### TGMC

TGMC 将多源异构图、GAT+GRU、掩码重建和多视图对比学习用于内部用户行为异常检测。OpenAlex 记录：Yuan 等，2026；本次未取得 DOI 和正式卷期信息。

这是当前最接近的“图 + 对比学习”工作，必须在相关工作和方法差异中主动处理：

- TGMC 构造异构图并使用专用于异常检测的图编码器；
- AdaGraph 不新增图编码器，校正的是 TS2Vec 训练中的实例正关系权重；
- TGMC 采用多视图掩码对比；
- AdaGraph 使用画像先验、EMA 反馈和 KL 信任域，把图更新限制在稳定行为关系附近。

如果最终检索确认 TGMC 已正式发表且代码可用，应尽量加入实验对照；至少需要提供概念对照表。

## 六、评价规范

- Kim 等指出 point-adjust 会系统性高估事件级检测能力，建议使用更严格的评价和局部事件指标。已核实：AAAI 2022，DOI:10.1609/AAAI.V36I7.20680。
- Wu 与 Keogh 指出部分时序异常检测基准存在缺陷，可能制造虚假进展。已核实：IEEE TKDE，DOI:10.1109/TKDE.2021.3112126。
- Demšar 系统讨论多数据集、多分类器的统计比较。已核实：JMLR 2006，DOI:10.5555/1248547.1248548。

AdaGraph 实验应同时报告点级指标、固定预算事件命中、延迟和 bootstrap 置信区间，不依赖 point-adjust 作为主要证据。

## 七、相关工作可直接采用的段落骨架

时序自监督表示学习通过时间邻域、层次对比、软对比或聚类原型学习无标签表示。TS2Vec 通过层次化实例与时间对比获得时间戳级表示；SoftCLT 进一步用数据空间距离缓解假负样本，但其实例关系在训练前固定。NNCLR、PCL 和 SwAV 分别从近邻、原型与聚类分配获得语义正样本，说明固定实例判别目标并不充分。假负样本检测与去偏方法进一步指出，随机负样本可能来自同一语义类别，需要动态识别或概率校正。上述方法主要让正样本来源更丰富，但没有解决企业用户关系中的稳定先验与表示反馈之间的冲突。

内部威胁检测研究从规则、统计和行为画像发展到序列模型、图模型与实时活动级检测。LAN 通过活动级图学习同时建模时间依赖和跨序列关系；近期工作进一步结合异构图、知识提示或多视图对比。与这些方法不同，AdaGraph 不构造新的内部威胁检测器，而是在 TS2Vec 的训练目标中用画像先验锚定用户软正关系，并通过有限表示反馈校正假负样本。该方法的关键是信任域约束下的软图更新，以及异常用户不能被无约束地吸收到正常表示核心。
