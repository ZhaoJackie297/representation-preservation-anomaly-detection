Date: 2026-11-18.

Status: fixed 10-seed r4.2 development matrix completed.

The r4.2 test split is a development test, not external confirmation.

## 1. Fixed matrix

No hyperparameter was tuned during this run.

```text
training: A0-official, A0-matched, A1-Cov
scoring:  plain_l1, PAI-A1
seeds:    20261116-20261125
models:   30
```

The point-level labels are canonical malicious account days. The event endpoint
is canonical three-day production recall with 24 test and 46 validation events.

Test PR-AUC and ROC-AUC are compared with paired seed-level tests. The four
pre-declared primary tests are:

```text
A1-Cov + PAI-A1 versus A0-official + plain:
  PR-AUC
  K=10 canonical event recall

A1-Cov + PAI-A1 versus A0-matched + PAI-A1:
  PR-AUC
  K=10 canonical event recall
```

Holm correction covers exactly these four test endpoints.

Values are mean over ten seeds. Event hits are canonical K=10 hits over 24

## 5. Decomposition

PAI scoring is consistently positive:

| Training representation | Test Delta PR-AUC | Test Delta ROC-AUC |
| --- | ---: | ---: |
| A0-official | +0.003745 | +0.064438 |
| A0-matched | +0.003738 | +0.080817 |
| A1-Cov | +0.004544 | +0.058301 |

All three PAI PR/ROC effects are positive on 10/10 seeds.

Coverage-batch construction without soft instance weights is not sufficient:

```text
A0-matched + PAI - A0-official + PAI:
  Delta PR  = -0.000760, 9/10 seeds negative
  Delta ROC = -0.006998, 9/10 seeds negative
  Delta K10 =  0.0
```

The positive result therefore comes from the combination of common coverage
and soft instance supervision, not from merely replacing random batches with
the coverage table.

The fixed joint method also beats `A0-official + PAI-A1` on point-level metrics:

```text
Delta PR  = +0.001745, 10/10 positive
Delta ROC = +0.007828, 9/10 positive
```

Its K=10 event increment over `A0-official + PAI-A1` is `+0.05`, but the 95% CI
crosses zero. The event advantage is established against the plain official
baseline, not against a PAI-only baseline.

## 7. What this supports

Supported:

1. PAI scoring improves point-level detection under all three training
   representations.
2. The fixed `A1-Cov + PAI-A1` method beats the standard official
   `A0-official + plain` baseline on PR-AUC and canonical K=10 event recall
   across the fixed 10-seed matrix.
3. Coverage-aware training adds a smaller but positive increment over
   `A0-matched + PAI-A1` on PR-AUC and K=10 event recall after Holm correction.
4. Coverage batches alone do not explain the gain; the interaction with soft
   instance supervision is necessary.

Not supported:

1. r4.2 is not external confirmation.
2. The method does not show a confirmed event-level improvement over
   `A0-official + PAI-A1`.
3. Independent relation-channel benefit is still not established.
4. Results from r4.2 do not transfer automatically to r5.2, CLUE-LDS, SMD, or
   r6.2.
